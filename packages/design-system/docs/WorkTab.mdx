# Work Tab

열려 있는 업무 화면을 전환 · 관리하는 **Workspace Navigation**입니다.
같은 화면 안의 콘텐츠 View 전환은 **Basic Tab**(`Tab`)을 쓰고, 둘을 혼용하지 않습니다.

```tsx
import { WorkTab, WORK_TAB_LIMIT } from '@kiwoompay/design-system';

<WorkTab value={activeId} onChange={go} onClose={closeTab} actions={tabActions}>
  {tabs.map((tab) => (
    <WorkTab.Item key={tab.id} value={tab.id} closable={!tab.fixed}>
      {tab.title}
    </WorkTab.Item>
  ))}
</WorkTab>
<WorkTab.ActionMenu count={tabs.length} actions={tabActions} />
```

WorkTab은 Active 값과 버튼 이벤트만 다룹니다. 열린 Tab 목록 · 화면 이동 · 개수 제한은 화면(앱)이 관리합니다.

## 4. Tab Action

<Canvas of={WorkTabStories.ActionMenu} />

- **Tab Action Menu**: Action Menu Trigger(`WorkTab.ActionMenu` "열린 화면 N", Active Tab의 •••)를
  누르면 Tab 관리 메뉴를 레이어로 노출합니다.
- Action을 고르면 해당 Work Tab을 열기 · 고정 · 닫기 처리합니다(`onSelect`에서 화면이 처리).
- **Layer Pattern**: Modal이 아닌 Trigger 종속형 레이어. 바깥 클릭 · Esc로 닫힙니다.
- "열린 화면 N" Trigger는 Work Tab 줄 오른쪽 끝에 둡니다(Page Layout의 `workTabActions` 슬롯). 메뉴는 Trigger 오른쪽에 맞춰 열립니다.
- 닫기(X)를 누르면 해당 Work Tab을 종료합니다(`onClose`).

## 토큰 · 확인 필요

- `work-tab/*` (`tokens/custom/work-tab.json`). 색은 모두 Figma 색 alias
- 시안 측정: Item 높이 40 · 좌우 여백 12 · 아이콘 24 · 간격 4 · 위 모서리 8 · Active 아래 선 2px,
  메뉴 폭 200 · 안쪽 여백 8 · 항목 높이 33 · 모서리 8
- **임시 값(TODO)**: 메뉴명 말줄임 기준 폭 160, Active Tab의 •••로 열 때 Tab ↔ 메뉴 4, 메뉴 항목 Hover ·
  비활성 표현, Trigger ↔ 메뉴 8
- 시안의 State 예시는 Default · Hover Tab 폭이 내용보다 넓지만 Workspace Bar 예시는 내용 폭에 맞춰져
  있어 **내용 폭 기준**으로 구현했습니다. Hover 시 닫기(X)가 나타나며 그만큼 Tab이 넓어집니다
- 고정 Tab의 표시(아이콘 등)는 시안이 없어 닫기 숨김만 제공합니다
