# Tab

동일 화면 또는 동일 영역 안에서 콘텐츠 View를 전환합니다.
열려 있는 업무 화면의 관리 · 닫기는 **Work Tab**을 씁니다(Tab과 구분).

```tsx
import { Tab } from '@kiwoompay/design-system';

<Tab value={view} onChange={setView}>
  <Tab.Item value="all">전체</Tab.Item>
  <Tab.Item value="wait" count={10}>승인대기</Tab.Item>
  <Tab.Item value="hold" disabled>보류</Tab.Item>
</Tab>;
{view === 'all' ? <AllList /> : <WaitList />}
```

Tab은 선택 값만 관리합니다. 선택에 따른 콘텐츠는 화면에서 바꿔 그립니다. (`value` · `defaultValue` · `onChange`)

## 4. Group & Layout

<Canvas of={TabStories.Layout} />

- **Content Width (기본)**: Label 길이에 따라 Tab Item 폭이 정해집니다. Tab은 콘텐츠 중심입니다.
- **Equal Width (`fullWidth`)**: LNB처럼 2개 View를 같은 비율로 둘 때는 부모가 폭을 정합니다. Item에 임의 고정 폭을 주지 않습니다.
- 긴 Label은 말줄임 처리됩니다.

### Button Tab

<Canvas of={TabStories.ButtonTab} />

- 높이 32 · Active는 Primary 50 배경 + Primary 테두리. Equal Width는 부모 Layout에서 제어합니다(`fullWidth`).

## 토큰 · 확인 필요

- `tab/*` (`tokens/custom/tab.json`, 색은 모두 Figma 색 alias), 글자 역할 `tab-md` · `tab-active-md` · `tab-sm` · `tab-count-md`
- Number Badge Soft 색 `badge/number/soft-*` (`tokens/custom/badge.json`)
- 시안에 없어 **임시 값(TODO)** 인 것: Item 좌우 여백 4 · Item 간격 24, Button Tab 최소 폭 76 · 좌우 여백 16 · 간격 8, 비활성 Badge 색, Hover 표현(미구현)
- Title Tab 변형은 시안이 없어 만들지 않았습니다.
