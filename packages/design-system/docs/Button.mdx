# Button

사용자가 **Action을 실행**하는 버튼입니다. 색은 Action의 역할과 위험도를 구분하는 기준으로 씁니다.
화면 이동은 `TextLink`, 화면 안의 가벼운 기능 실행은 `TextButton`을 씁니다.

```tsx
import { Button, TextButton, TextLink } from '@kiwoompay/design-system';

<Button variant="primary" onClick={save}>저장</Button>
<Button variant="neutral" appearance="line">취소</Button>
<Button leadingIcon={<Icon name="download" />}>다운로드</Button>
<Button iconOnly icon={<Icon name="download" />} aria-label="다운로드" />
<Button loading>저장</Button>
```

## 2. Structure — appearance · size

- `appearance`: `solid`(채움) · `line`(테두리). 아이콘만 있는 버튼은 `iconOnly`.
- `size`: `lg` · `md`(기본) · `sm`. 높이는 `control/height/*` 토큰이다.

- 버튼은 텍스트 길이에 맞춰 폭이 정해집니다. 아이콘 전용만 정사각형 고정이며, 동일 폭이 필요하면 Container에서만 예외로 적용합니다.
- 긴 텍스트는 말줄임(`…`) 처리되고 부모 폭을 넘지 않습니다.

<table>
  <thead>

    </tr>
    <tr>
      <td>Pressed</td>
      <td>클릭 중</td>
      <td>Default보다 두 단계 어두운 배경색</td>
    </tr>
    <tr>
      <td>Disabled</td>
      <td>조건 미충족</td>
      <td>
        <code>disabled</code> · 이벤트 차단
      </td>
    </tr>
    <tr>
      <td>Loading</td>
      <td>API 처리 중</td>
      <td>
        <code>loading</code> · 로딩 아이콘 + "처리 중" 표시, 재클릭 차단
      </td>
    </tr>
  </tbody>
</table>

- Focus는 공통 포커스 스타일(`:focus-visible`)을 따릅니다. 버튼에서 따로 정의하지 않습니다.
- `loading` 중에는 내용이 `loading` 아이콘과 **"처리 중"** 으로 바뀌고, 폭은 그 내용에 맞춰집니다. 문구는 `loadingText`로 바꿀 수 있고, 아이콘 전용 버튼은 아이콘만 바뀝니다.
- `onClick`이 호출되지 않고 `aria-busy`가 설정됩니다. `disabled`가 아니므로 색은 Default 그대로입니다. 로딩 아이콘은 회전하지 않습니다(애니메이션 없음).

## 5. Placement

- 페이지 상단 우측에 **보조 Action → 최종 Action** 순서로 둡니다. (`[엑셀 다운로드] [가맹점 등록]`)
- Primary Solid와 Danger Solid는 **같은 그룹에 두지 않습니다.** 위험 확인 팝업은 `[취소(Neutral Line)] [강제 취소(Danger Solid)]`로 구성합니다.

## 7. TextButton · TextLink

- **TextButton** — 화면 **안**에서 기능을 실행합니다. 배경·테두리가 없고 Hover에서만 Primary 50 배경이 생깁니다(밑줄 없음). `md` 13 Bold · `sm` 12 SemiBold. `variant`: `primary` · `neutral`(Figma에 없음, 임시), `size`: `md` · `sm`.
- **TextLink** — 화면 **이동**에 씁니다(`<a>`). 모든 상태에서 밑줄을 유지합니다. 본문 안 이동은 텍스트+밑줄로 씁니다.

```tsx
<TextButton onClick={openHistory}>이력조회</TextButton>
<TextButton variant="neutral">전체보기</TextButton>
<TextLink href="/guide">이용가이드 안내</TextLink>
```

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>화면·팝업당 Primary는 1개만 둔다</td>
      <td>Primary Solid를 여러 개 나란히 둔다</td>
    </tr>
    <tr>
      <td>최종 Action을 가장 오른쪽에 둔다</td>
      <td>보조 Action을 최종 Action보다 오른쪽에 둔다</td>
    </tr>
    <tr>
      <td>Danger는 복구하기 어려운 Critical Action에만 쓴다</td>
      <td>일반 삭제·해제에 Danger를 쓴다 (→ Dark)</td>
    </tr>
    <tr>
      <td>Primary Solid와 Danger Solid는 다른 그룹으로 분리한다</td>
      <td>같은 줄에 Primary Solid와 Danger Solid를 함께 둔다</td>
    </tr>
    <tr>
      <td>아이콘은 앞 또는 뒤 한쪽에만 둔다</td>
      <td>앞·뒤 아이콘을 동시에 쓴다</td>
    </tr>
    <tr>
      <td>
        아이콘 전용 버튼에는 <code>aria-label</code>을 준다
      </td>
      <td>의미가 불분명한 아이콘만 단독으로 쓴다</td>
    </tr>
    <tr>
      <td>
        처리 중에는 <code>loading</code>으로 재클릭을 막는다
      </td>
      <td>처리 중 버튼을 그대로 두어 중복 요청을 허용한다</td>
    </tr>
    <tr>
      <td>색·크기는 prop으로 고른다</td>
      <td>
        <code>className</code>/<code>style</code>으로 색·높이를 덮어쓴다
      </td>
    </tr>
  </tbody>
</table>
