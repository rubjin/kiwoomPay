# CPID List Item

CPID와 가맹점명, 상태를 한 줄 카드로 보여주는 목록 항목입니다. CPID 목록에서 하나를 골라 상세를 볼 때 씁니다.

```tsx
import { CpidListItem, Badge } from '@kiwoompay/design-system';

<CpidListItem
  cpid="CP0012345"
  merchantName="키움페이 강남점"
  status={
    <Badge tone="success" size="sm" dot>
      사용중
    </Badge>
  }
  selected={selected === 'CP0012345'}
  onClick={() => setSelected('CP0012345')}
/>;
```

- 상태는 `status`에 Badge(sm · dot)를 넣습니다. 사용중 → `success`, 중지 → `error`.
- 항목은 버튼입니다. 선택값은 화면이 관리하고 `selected`로 넘깁니다(`aria-pressed` 자동).
- CPID · 가맹점명이 길면 한 줄 말줄임합니다.

## Spec

- 폭은 부모를 채움(시안 288) · 높이 58(테두리 제외 56) · 반경 8 · 테두리 1 (Figma CPID/List Item)
- 여백 위아래 8 · 좌우 12(테두리 안쪽), CPID 줄 높이 20(Badge sm) · 가맹점명 줄 간격 2
- CPID 13 SemiBold `Text/Heading` · 가맹점명 12 Regular `Text/Label`
