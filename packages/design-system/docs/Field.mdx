# Field

사용자가 값을 **직접 입력하거나 선택**하는 폼 컴포넌트 모음입니다.

## 1. Size · Spec

- `size`: `md`(기본, Default 40) · `sm`(Small 32) · `lg`(48, md와 글자 · 여백 같음 — 즐겨찾기 편집 검색 등 넓은 Modal 상단 검색). 폭에는 **고정 variant가 없습니다.** 내용 기준으로 늘어나고, 부모 폭을 채우려면 `fullWidth`를 씁니다.
- 같은 줄에 Button과 놓을 때는 같은 size를 맞춥니다 (높이 40 / 32).

## 3. Text Field — Content

`leadingIcon`(예: 검색), `trailingIcon`, `suffix`(예: 원), `clearable`(값이 있을 때 지우기 버튼)을 조합합니다.

## 4. Select Box

- 옵션은 `options={[{ value, label, disabled? }]}`로 넘깁니다. 선택값은 `value` / `defaultValue` / `onChange(value, option)`.
- `name`을 주면 선택값이 hidden input으로 함께 제출되어 JSP form 전송에 쓸 수 있습니다.
- 드롭다운 상태: Default · Hover · Selected · Disabled 항목, 항목이 많으면 **스크롤**, `loading`이면 **불러오는 중**, 옵션이 없으면 **빈 상태** 문구.
- 패널(Figma Select Box 2026-11-12): 여백 8 · 항목 간격 8 · 항목 여백 8 · 최대 높이 190(넘으면 스크롤) · 로딩 · 빈 상태 174. 항목 글자 md `typo-14-regular` · sm `typo-13-medium`.
- 바깥 영역 클릭, `Esc`로 닫힙니다.
- 열린 상태에서 **스크롤 · 로딩 · 빈 상태**가 되면 트리거 테두리가 번짐 없이 Primary 2px로 진해집니다 (`field/strong-border-width`).

## 4-1. Multi-select Dropdown

여러 항목을 고르는 드롭다운입니다. 트리거 · 크기 · 상태(Negative · Disabled · 열림 강조)는 Select Box와 같습니다.

- 선택값은 배열입니다: `value` / `defaultValue` / `onChange(value, options)`. 값은 **옵션 순서**로 정렬됩니다.
- 항목을 누르면 바로 반영되고 패널은 **열린 채로** 유지됩니다(확인 버튼 없음). 바깥 클릭 · `Esc`로 닫습니다.
- 패널 맨 위 **옵션 검색**(`searchable`, 기본 표시)으로 목록을 거릅니다. 닫으면 검색어가 지워집니다.
- **전체**(`selectAll`, 기본 표시)는 지금 보이는(검색된) 항목 중 선택 가능한 것만 선택 · 해제합니다. 일부만 선택되면 – 표시입니다.
- 트리거 표시: 선택한 항목 이름을 **쉼표로 나열**하고 넘치면 말줄임(…)합니다. 다르게 보여야 하면 `renderValue`를 씁니다.
- `name`을 주면 선택값마다 hidden input이 하나씩 제출됩니다(JSP form 전송).
- 패널 폭은 트리거 폭을 따릅니다. 패널 최대 높이 md 276 · sm 210, 넘으면 목록만 스크롤됩니다. 항목 글자 md 14 · sm 13, 항목 높이 36 · 간격 4 · 좌우 여백 10 · 체크박스 16. 로딩 · 빈 상태 패널은 높이 190. 항목 반경 4.

## 6. Textarea

- `rows`(기본 3)로 높이가 정해지고 크기 조절 핸들은 없습니다.
- `showCounter` + `maxLength`로 우측 하단에 `0 / 200`을 표시합니다. 카운터는 박스 안에 겹쳐 놓이므로 입력이 마지막 줄까지 길어지는 용도라면 `rows`를 늘립니다.

<Canvas of={TextAreaStories.Sizes} />

## 7. Date Field · Date Range Field

- 숫자만 입력해도 `YYYY-MM-DD`로 자동 정렬되고, `onChange`에는 정렬된 문자열이 전달됩니다 (`DateRangeField`는 `{ start, end }`).
- 날짜 ↔ 달력 아이콘 간격은 4, 기간 구분(~) 양옆은 8입니다(Figma Date Field · Date Range Field).
- Date Picker는 포함하지 않습니다. 달력 아이콘을 누르면 `onCalendarClick`이 호출되니 Picker는 직접 연결합니다. `disabled` · `readOnly`에서는 아이콘이 비활성입니다.
- 날짜 형식 검증(존재하는 날짜인지, 시작일 ≤ 종료일)은 하지 않습니다. 검증 결과는 `feedback`으로 전달합니다.

## 8. Field — Label · Helper

- 라벨은 필드 **왼쪽**에 가로로 놓이고 필드와 세로 가운데가 맞습니다. 안내 문구(Helper)는 필드 **아래**, 필드 왼쪽에 맞춰 8px 간격으로 놓입니다.
- `required`는 라벨 옆에 Primary 색 `*`를 표시합니다. 라벨 폭은 `labelWidth`로 여러 필드에 맞춥니다.
- 안쪽 컨트롤은 `id` · `size` · `feedback` · `disabled`를 자동으로 받습니다. 컨트롤에 직접 준 prop이 우선합니다.
- `feedback`을 주면 안내 문구가 같은 색(초록 / 빨강)이 됩니다.

## 사용 위치 규칙

- 검색 영역: `SearchField` + `Button`(조회). 상세 조건이 많으면 `Field`로 라벨을 붙인 `TextField` · `SelectBox` · `DateRangeField`를 조합합니다.
- 입력 폼: 라벨 폭을 `labelWidth`로 통일하고, 필수 항목에만 `required`를 붙입니다.

## 토큰

- 크기: `control/height/*`(Button과 공유), 여러 필드가 함께 쓰는 `field/radius·gap·icon-size/trailing·label-gap-top` (`tokens/custom/field.json`). 그 밖의 컴포넌트 전용 크기 · 간격은 `*.module.scss` 맨 위 SCSS 변수
- 색: `field/*`, `select/*` — 모두 Figma 색 토큰 alias.
- 글자: `typo-14-regular`(md), `typo-13-medium`(sm), `typo-12-regular`(Helper · Counter), `typo-13-bold`(Label)
- 포커스 번짐은 `shadow/focus`(`0 0 4px 0 rgba(36, 132, 198, 0.30)`)입니다. 드롭다운 최대 높이(`select/panel-max-height`)와 로딩·빈 상태 높이는 시안 픽셀로 근사한 **임시 값(TODO)** 입니다.
