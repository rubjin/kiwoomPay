## 2. Header Global Search

내부관리자 GUI의 Header 검색 · Utility 배치를 기준으로 표현합니다. 검색 결과 · 이동 · 권한 정책은 화면설계서 및 개발 확인 사항을 따릅니다.

- **이번 가이드에서 정의**: Header 내 검색 영역 · 검색 대상 5종(상호명 · 사업자번호 · 가맹점ID · 그룹ID · CPID) · 결과 선택 후 가맹점 통합 상세조회 이동
- **추후 요구사항 확정 후 정의**: Header 높이와 전체 배치 · 유틸리티(세션 · 마스킹 · 다운로드센터 · 알림) 구성 · 자동완성/결과 레이어의 상세 표현과 상태
- 입력 UI는 `SearchField`(placeholder "업무 대상을 검색해주세요")를 씁니다. Header 컴포넌트는 Header 시안 확정 후 제공합니다.

## 3. LNB Menu Search

상호명 · 가맹점ID 같은 업무 대상은 검색하지 않으며, 결과에는 메뉴명과 메뉴 경로를 함께 제공합니다. `Lnb`에 내장되어 있습니다(LNB Guide 6. Menu Search).

1. **검색 대상**: 메뉴명만 검색합니다.
2. **검색 결과**: 부분 일치 결과에 메뉴명과 상위 메뉴 경로를 함께 표시합니다.
3. **이동**: 결과를 선택하면 해당 업무 화면으로 이동합니다.
4. **상태**: Result / Empty 상태와 상세 치수는 LNB Guide를 따릅니다.

## 4. Body Search — SearchPanel

화면 본문 검색은 **검색 조건 카드(`SearchPanel`)** 하나로 만듭니다(KWP GUI — 통합 거래내역 · 정산 실행 · 다운로드 센터). 기본 조건과 상세 조건으로 나누고, 실제 검색 조건 · 기본값 · 필수 여부는 각 화면설계서에서 정의합니다. 부품 상세(줄 · 격자 · 접힘 · 상자형)는 [Search Panel Guide](?path=/docs/composites-search-search-panel--guide)를 봅니다.

```tsx
import { SearchPanel, Field, DateRangeField, SelectBox, TextField } from '@kiwoompay/design-system';

<SearchPanel
  onSearch={search}
  onReset={reset}
  loading={loading}
  detail={
    <SearchPanel.Grid columns={5}>
      <Field label="고객명">
        <TextField fullWidth value={customer} onChange={onCustomer} />
      </Field>
    </SearchPanel.Grid>
  }
>
  <Field label="조회기간">
    <DateRangeField value={period} onChange={setPeriod} />
  </Field>
  <Field label="결제수단">
    <SelectBox options={payOptions} value={pay} onChange={setPay} />
  </Field>
</SearchPanel>;
```

### Validation

- 입력 오류 · 최대 길이 · 필수 피드백은 Field의 `feedback` · `helperText` · `required`로 표시합니다.
- 상태(Default · Focus · Filled · Disabled · Error)는 각 필드 컴포넌트의 상태를 그대로 씁니다.

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>검색 위치(Header · LNB · 본문)에 맞는 대상만 검색한다</td>
      <td>LNB 메뉴 검색에서 상호명 · 가맹점ID를 찾게 한다</td>
    </tr>
    <tr>
      <td>자주 쓰는 조건은 기본, 나머지는 상세 조건에 둔다</td>
      <td>모든 조건을 기본 줄에 늘어놓는다</td>
    </tr>
    <tr>
      <td>필드 라벨은 필드 왼쪽(간격 8)에 두고 버튼은 필드 줄에 맞춘다</td>
      <td>화면마다 버튼 위치 · 순서([새로고침] · [조회] · [상세 검색])를 바꾼다</td>
    </tr>
