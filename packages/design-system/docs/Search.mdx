## 2. Header Global Search

내부관리자 GUI의 Header 검색 · Utility 배치를 기준으로 표현합니다. 검색 결과 · 이동 · 권한 정책은 화면설계서 및 개발 확인 사항을 따릅니다.

- **이번 가이드에서 정의**: Header 내 검색 영역 · 검색 대상 5종(상호명 · 사업자번호 · 가맹점ID · 그룹ID · CPID) · 결과 선택 후 가맹점 통합 상세조회 이동
- **추후 요구사항 확정 후 정의**: Header 높이와 전체 배치 · 유틸리티(세션 · 마스킹 · 다운로드센터 · 알림) 구성 · 자동완성/결과 레이어의 상세 표현과 상태
- 입력 UI는 `SearchField`(placeholder "업무 대상을 검색해주세요")를 씁니다. Header 컴포넌트는 Header 시안 확정 후 제공합니다.

## 3. LNB Menu Search

상호명 · 가맹점ID 같은 업무 대상은 검색하지 않으며, 결과에는 메뉴명과 메뉴 경로를 함께 제공합니다. `Lnb`에 내장되어 있습니다(LNB Guide 6. Menu Search).

1. **검색 대상**: 메뉴명만 검색합니다.
2. **검색 결과**: 부분 일치 결과에 메뉴명과 상위 메뉴 경로를 함께 표시합니다.
3. **이동**: 결과를 선택하면 해당 업무 화면으로 이동합니다.
4. **상태**: Result / Empty 상태와 상세 치수는 LNB Guide를 따릅니다.

## 4. Body Search Area

화면 본문 검색은 **기본 조건**과 **상세 조건**으로 구성합니다. 아래 필드 조합은 예시이며, 실제 검색 조건 · 기본값 · 필수 여부는 각 화면설계서에서 정의합니다.

```tsx
import { SearchArea, Field, DateRangeField, SelectBox, SearchField, Button } from '@kiwoompay/design-system';

<SearchArea
  onSearch={search}
  onReset={reset}
  loading={isFetching}
  detail={
    <>
      <Field label="결제수단" labelPosition="top" size="sm">
        <SelectBox options={payOptions} value={pay} onChange={setPay} />
      </Field>
    </>
  }
  detailActions={
    <>
      <Button size="sm" variant="neutral" appearance="line">조건 저장</Button>
      <Button size="sm" appearance="line">내 검색조건</Button>
    </>
  }
>
  <Field label="조회기간" labelPosition="top" size="sm">
    <DateRangeField value={period} onChange={setPeriod} />
  </Field>
  <Field label="검색어" labelPosition="top" size="sm">
    <SearchField placeholder="가맹점명 또는 가맹점ID" value={keyword} onChange={onKeyword} />
  </Field>
</SearchArea>;
```

## 토큰 · 확인 필요

- `search-area/*` (`tokens/custom/search.json`), Field 라벨 위 배치 간격 `field/label-gap-top`
- 간격(시안 측정): 필드 간격 16 · 필드 ↔ 버튼 16 · 버튼 간격 8 · 라벨 ↔ 필드 4. 필드 · 버튼 높이 32
- 상세 조건을 펼치면 기본 조건 아래 16에 구분선(`Line/Subtle` 1px), 구분선 아래 24에 상세 조건 줄
- 시안의 회색 박스(배경 · 테두리)는 가이드의 다른 섹션과 같은 설명용 카드라 SearchArea에 포함하지 않았습니다. 박스가 필요하면 화면 레이아웃(카드 · 영역)에서 감쌉니다
