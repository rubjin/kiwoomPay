# Section Heading

카드 · 영역의 제목 줄입니다. `[label] 제목 [description] [addon] ··· [actions]` 한 줄과, 필요하면 아래 줄 문맥으로 구성됩니다.
`PageLayout.Section` · `SearchPanel` · `ResultPanel` · `AppliedFilters` · `ResultSummary` · `FormSection`이 내부에서 이 컴포넌트를 씁니다.
화면에서 카드 없이 제목 줄만 필요할 때(Modal 본문, Grid 위 등) 직접 씁니다.

| prop          | 내용                                                                               |
| ------------- | ---------------------------------------------------------------------------------- |
| `size`        | `lg` 18 Bold(기본: Section · 검색 조건 · 폼 카드) · `md` 16 Bold(조회 결과)        |
| `subtle`      | 한 단계 옅은 글자색 (한 줄 카드: 적용된 검색 조건 · 조회 요약)                     |
| `as`          | `h2`(기본) · `h3` · `h4`                                                           |
| `label`       | 제목 앞 작은 이름 10 Regular (선택 CPID)                                           |
| `description` | 제목 옆 설명 12 Regular, 제목과 12                                                 |
| `addon`       | 제목 바로 옆 (접기 아이콘 · 표시항목설정 버튼 · Badge), 간격 8                     |
| `actions`     | 오른쪽 끝 (버튼 · 탭), 항목 사이 8                                                 |
| `actionsGrow` | 오른쪽이 남는 폭을 채움 (ActionBar). 제목 묶음은 줄지 않음                         |
| `children`    | 제목 아래 줄 문맥 (ContextChip · 상태 Badge). 있으면 오른쪽은 위에 맞춤, 줄 간격 8 |

- 긴 제목은 말줄임
- 간격은 쓰는 곳이 CSS 변수로 바꾼다: `--section-heading-gap`(제목 묶음 ↔ 오른쪽, 기본 16) · `--section-heading-actions-gap`(오른쪽 항목 사이, 기본 8)
- 색 토큰: `section-heading/title` · `title-subtle` · `label` · `description`

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>

  </thead>
  <tbody>
    <tr>
      <td>영역 제목은 SectionHeading(또는 이를 쓰는 Section · Panel)으로 그린다</td>

    </tr>
    <tr>
      <td>같은 카드 안의 제목은 같은 size</td>
      <td>카드 제목과 본문 중간 제목의 크기를 다르게 한다 (P02: 같은 레벨)</td>
