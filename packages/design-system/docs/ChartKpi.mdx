# Chart & KPI

대시보드(메인 > 대시보드 KWPC01010000)를 만드는 카드 · 지표 · 차트 부품입니다. 차트는 **Recharts**(확정 결정 "Chart 라이브러리"), 막대 목록은 라이브러리 없이 CSS로 그립니다.
그리드(표)가 아니므로 IBSheet는 쓰지 않습니다.

## 구성

| 부품                                    | 용도                                           | 주요 옵션                                                                                                                                         |
| --------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DashboardSection`                      | 영역 제목 줄(20 SemiBold) + 기준일 + 카드 격자 | `title` · `aside`                                                                                                                                 |
| `DashboardGrid`                         | 카드 격자, 칸 사이 12                          | `columns`(비율, 기본 4열) · `gap` 8 · 12 · `rowHeight`(시안 카드 높이)                                                                            |
| `DashboardCard`                         | 흰 카드(반경 12) + 제목 줄                     | `title` · `titleSize` xs 12 · sm 13 · md 14 · `info` · `period` · `titleAddon` · `linkLabel` + `onLinkClick` · `aside` · `gap` · `split` · `bare` |
| `KpiCard`                               | 상단 KPI                                       | `variant` hero · default · status · `tone` warning · error · `onClick`(카드 전체 버튼 + >)                                                        |
| `MetricSummary`                         | 값 + 증감 + 기준일                             | `value` · `unit` · `delta` · `deltaLabel` · `reference`                                                                                           |
| `KpiTile`                               | 카드 안 회색 칸 지표                           | `label` · `value` · `unit` · `delta` · `onClick`                                                                                                  |
| `Delta` · `MetricValue`                 | 증감 ▲▼(초록 · 빨강) · 값 + 단위               | `value` · `unit` · `size`                                                                                                                         |
| `BarList`                               | 가로 막대 목록                                 | `variant` compact · ranked · `max` · `ticks` · `axisLabel`                                                                                        |
| `ComboChart`                            | 막대(왼쪽 축) + 선(오른쪽 축)                  | `bars` · `line` · `leftAxis` · `rightAxis`(`unit`은 0 자리) · `formatValue`                                                                       |
| `DonutChart`                            | 비중 도넛 + 가운데 합계 + 범례                 | `items` · `centerLabel` · `centerValue`                                                                                                           |
| `CarouselNav`                           | 카드 안 ‹ 1 / 3 ›                              | 1쪽뿐이면 그리지 않음                                                                                                                             |
| `NoticeList` · `EventFeed` · `InfoChip` | 공지 · 당일 알림 · 작은 칩                     | `unread`(N) · `muted` · `onItemClick`                                                                                                             |

- 계열 색은 Chart Category 01~09 토큰을 순서대로 씁니다(07~09는 회색 — 비중이 작은 나머지 계열). 색을 바꿀 때만 `color`를 줍니다.
- Recharts는 색을 SVG 속성으로 쓰므로 토큰 값을 읽어 넣습니다(`useResolvedColors`) — 시스템 키컬러(`data-system`)가 바뀌면 차트 색도 바뀝니다.
- 차트 툴팁은 Chart Tooltip 토큰(어두운 배경 · 흰 글자). TODO(시안) 툴팁은 시안에 없어 임시 모양입니다.

## Do / Don't

- Do: 카드 폭 · 높이는 `DashboardGrid`의 `columns` 비율 · `rowHeight`로 맞춥니다. 반으로 나눈 뒤 다시 나누면(`[1, 1]` 안에 `[1, 1]`) 시안 폭(810 · 399)이 정확히 맞습니다.
- Do: 한 카드를 세로선으로 나눌 때는 `split` 카드 안에 `bare` 카드를 둡니다.
- Don't: 표(행 · 열 데이터)를 대시보드 목록 부품으로 그리지 않습니다 — 조회 결과 표는 `IbsheetGrid`.
- Don't: 카드 안 간격 · 폭을 인라인 스타일로 만들지 않습니다 (확정 결정 "인라인 스타일").
