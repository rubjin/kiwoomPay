# LNB

왼쪽 내비게이션입니다. 로고 · 접기, 메뉴 검색, View Tab(전체 메뉴 / 즐겨찾기), 1 · 2 · 3Depth 메뉴 트리로 구성됩니다.
라우팅에 의존하지 않으므로 메뉴 데이터와 현재 화면 id만 넘기면 됩니다.

```tsx
import { Lnb, type LnbMenuItem } from '@kiwoompay/design-system';

const menu: LnbMenuItem[] = [
  { id: 'dashboard', label: '대시보드', icon: 'home', href: '/dashboard' },
  {
    id: 'stats',
    label: '통계내역',
    icon: 'bar-chart',
    children: [
      {
        id: 'sales',
        label: '매출통계',
        children: [{ id: 'sales-total', label: '통합매출', href: '/stats/sales' }],
      },
    ],
  },
];

<Lnb
  items={menu}
  activeId="sales-total" // JSP가 현재 화면 id를 내려준다
  logo={<img src="/static/logo.svg" alt="키움페이" />}
  favoriteIds={myMenuIds}
  onFavoriteEdit={openFavoriteModal}
/>;
```

**State Rule** — 3Depth가 Active면 해당 2Depth는 Current + Open, 상위 1Depth는 Current를 유지합니다. Active는 실제 현재 화면에만 사용합니다. 현재 화면(`activeId`)이 바뀌면 상위 메뉴가 자동으로 펼쳐지고, 사용자가 연 다른 메뉴는 그대로 둡니다.

## 3. Mode

<Canvas of={LnbStories.Collapsed} />

- **Expanded**: 폭 240, 아이콘 + 메뉴명, 2 · 3Depth 노출, Search / View Tab 사용.
- **Collapsed**: 폭 48, 메뉴명 숨김, 1Depth 아이콘 유지, 현재 위치(Current) 표시 유지, 2 · 3Depth 숨김. 아이콘을 누르면 펼치고 해당 메뉴를 엽니다.
- 접기 · 펼치기는 표시 방식만 바꾸며 현재 메뉴 상태를 초기화하지 않습니다. (`collapsed` · `defaultCollapsed` · `onCollapsedChange`)

## 4. View · 5. Favorite

<Canvas of={LnbStories.Favorites} />
<Canvas of={LnbStories.FavoritesEmpty} />

- 전체 메뉴와 즐겨찾기는 같은 LNB 안에서 View만 바뀝니다. (`view` · `defaultView` · `onViewChange`)
- 즐겨찾기는 `favoriteIds`로 넘기며, 항목마다 메뉴명과 원래 메뉴 경로를 함께 보여줍니다.
- 등록된 메뉴가 없으면 Empty 안내와 [즐겨찾기 편집]을 보여줍니다.
- **편집은 Modal 패턴**입니다. '편집'을 누르면 `onFavoriteEdit`가 호출되고, 화면에서 Modal + 메뉴 트리(체크박스)로 고른 뒤 `favoriteIds`를 갱신합니다. 아래 Interactive 예시를 참고합니다.

## 6. Menu Search

- 입력 UI는 Field Guide의 SearchField(Small)를 그대로 씁니다.
- 실제 화면으로 이동하는 메뉴(하위 메뉴 없음) 중 이름에 검색어가 들어간 것을 보여줍니다. 일치 문자열은 Primary로 강조하고, 원래 메뉴 경로를 함께 표시합니다.
- 결과를 고르면 해당 메뉴로 이동하고 검색어를 비웁니다. 결과가 없으면 "검색 결과가 없습니다."를 보여줍니다.

## 토큰 · 확인 필요

- `lnb/*` (`tokens/custom/lnb.json`): 폭 · 행 높이 · 여백 · 색(모두 Figma 색 alias), 글자 역할 `lnb-*`
- 로고 이미지 파일이 필요합니다(예시는 임시 텍스트). 긴 메뉴명 툴팁은 Tooltip 컴포넌트가 생기기 전까지 기본 <code>title</code>을 씁니다.
- 시안에 없어 **임시 값(TODO)** 인 것: 3Depth Hover 표현, Active 점 크기, 탭 아래 구분선, 즐겨찾기 개수 글자. 가맹점관리자 모바일(Compact Navigation)은 별도 시안이 필요합니다.
