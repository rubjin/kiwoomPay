# Selection

선택 상태를 표시하고 바꾸는 컴포넌트 모음입니다. Checkbox · Radio · ToggleSwitch는 native `input`을 그대로 쓰므로
`checked` / `defaultChecked` / `onChange` 등 HTML 속성이 그대로 동작하고, controlled와 uncontrolled를 모두 지원합니다.

```tsx
import { Checkbox, RadioGroup, Radio, ToggleSwitch, Segmented } from '@kiwoompay/design-system';

<Checkbox label="약관에 동의합니다" checked={agree} onChange={(e) => setAgree(e.target.checked)} />

<RadioGroup value={type} onChange={setType}>
  <Radio value="personal" label="개인" />
  <Radio value="corp" label="법인" />
</RadioGroup>

<ToggleSwitch label="알림 받기" helperText="새 정산 내역이 생기면 알려줍니다." defaultChecked />

<Segmented value={unit} onChange={setUnit}>
  <Segmented.Item value="daily">일별</Segmented.Item>
  <Segmented.Item value="monthly">월별</Segmented.Item>
</Segmented>
```

## 1. Size

`size`: `md`(기본, Default 20) · `sm`(Small 16). Checkbox · Radio · ToggleSwitch가 공통입니다.

- 컨트롤과 라벨 간격은 8px, 라벨과 부가 설명 간격은 4px입니다.
- 라벨은 `md` 14px Regular, `sm` 13px Regular, 부가 설명은 12px Regular입니다.
- Segmented 옵션은 높이 32 · 최소 폭 60 · 좌우 12 · 12px 글자(선택 12 SemiBold)이고, 옵션끼리 테두리를 겹쳐 붙입니다(바깥 모서리만 Radius 6).

## 2. Checkbox

- **Off · On · Indeterminate**: `indeterminate`는 일부만 선택된 상태를 **표시만** 합니다. 전체 선택 체크박스에서 쓰고, `checked`는 직접 계산합니다.
- **Disabled**: `disabled`. 선택된 상태는 회색 배경에 흰 체크로 표시됩니다.
- **Content**: `label`만 · `label + helperText` · 라벨 없이(이 경우 `aria-label`을 줍니다).
- 여러 개를 묶을 때는 `SelectionGroup`을 쓰면 항목 간격 8px로 세로 정렬됩니다. `direction="horizontal"`로 가로 나열도 가능합니다.

## 3. Radio

- `RadioGroup`이 선택값(`value` / `defaultValue` / `onChange(value)`)과 `name`, `size`, `disabled`를 관리합니다. 그룹 안의 `Radio`는 `value`만 주면 됩니다.
- 같은 그룹에서는 **하나의 항목만** 선택됩니다. 선택하면 Primary 링 2px와 점이 표시됩니다.
- `RadioGroup`은 `direction="horizontal"`로 가로 배치할 수 있습니다.
- `RadioGroup` 없이 쓸 때는 `name`을 직접 주고 native 속성을 씁니다.

## 4. ToggleSwitch

- 설정이나 기능의 상태를 **즉시** 켜고 끌 때 씁니다. 저장 버튼을 눌러야 반영되는 선택에는 Checkbox를 씁니다.
- `role="switch"`로 렌더링됩니다. 움직임(애니메이션)은 motion 토큰이 정해지면 추가합니다.
- 여러 개는 `SelectionGroup`으로 묶습니다.

## 5. Segmented

`Segmented`(그룹) 안에 `Segmented.Item`을 둡니다. 내부는 native radio라서 같은 `name` 그룹으로 묶이고 방향키로도 이동합니다.

- 선택값은 `value` / `defaultValue` / `onChange(value)`. 클릭 즉시 값이 바뀝니다.
- 상태: Default · Selected · Disabled. 그룹 전체를 비활성화하려면 `Segmented`에 `disabled`를 줍니다.
- 긴 라벨은 말줄임 처리됩니다.
- 크기: `size` sm 32(기본) · **md 40** — 검색 조건 줄처럼 필드 높이 40과 나란히 둘 때 (폭은 글자 + 좌우 12). `fullWidth`: 부모 폭을 채우고 옵션을 같은 폭으로.

**언제 쓰나**

- **전체 옵션 노출**: 선택하기 전에 모든 옵션을 한눈에 보고 비교해야 할 때.
- **Single Select**: 하나의 그룹에서는 하나의 옵션만 선택합니다.
- **즉시 전환**: 별도로 펼치지 않고 한 번 선택으로 값을 바꿉니다.
- **Select Box를 쓰는 경우**: 전체 옵션을 항상 보여줄 필요가 없거나, 옵션 수 · 라벨 길이 때문에 한 화면에서 비교하기 어려울 때는 `SelectBox`를 씁니다.

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>

  <tbody>
    <tr>
      <td>
        전체 선택 대상 중 일부만 선택되면 전체 선택에 <code>indeterminate</code>를 준다
      </td>
      <td>일부만 선택됐는데 전체 선택을 체크 상태로 둔다</td>
    </tr>
    <tr>
      <td>토글은 누르면 바로 반영되는 설정에만 쓴다</td>

    </tr>
    <tr>
      <td>하나만 고르는 곳은 Radio(또는 Segmented)를 쓴다</td>
      <td>하나만 고르는 곳에 Checkbox를 쓴다</td>
    </tr>
    <tr>
      <td>옵션이 많으면 SelectBox로 바꾼다</td>
      <td>긴 옵션을 Segmented에 억지로 넣어 말줄임이 생기게 한다</td>
    </tr>
    <tr>
      <td>
        라벨이 없는 Checkbox에는 <code>aria-label</code>을 준다
      </td>
      <td>의미를 알 수 없는 체크박스만 단독으로 둔다</td>
    </tr>
    <tr>
      <td>
        묶음은 <code>SelectionGroup</code> / <code>RadioGroup</code>으로 감싼다
      </td>
      <td>
        항목마다 <code>margin</code>으로 간격을 직접 맞춘다

## 토큰

- 크기: 컨트롤 크기 `selection/size/md·sm`(여러 컴포넌트 공유, `tokens/custom/selection.json`). 그 밖의 컴포넌트 전용 크기 · 간격은 `*.module.scss` 맨 위 SCSS 변수(`Checkbox` · `Radio` · `ToggleSwitch` · `Segmented` · `SelectionItem`)
- 색: 모두 Figma 색 토큰 alias (`selection/*`, `toggle/*`, `segmented/*`)
- 글자: `typo-14-regular`(md) · `typo-13-regular`(sm) · `typo-12-regular`(부가 설명) · `typo-12-medium`(Segmented 옵션) · `typo-12-semi-bold`(Segmented 선택)
