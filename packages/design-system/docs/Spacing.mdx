# Spacing

Gap(요소 사이 간격)과 Padding(요소 안쪽 여백)에 공통으로 쓰는 Spacing Scale입니다.
값은 Figma `space/*` 변수(`tokens/figma/space.json`)를 그대로 씁니다.

시안 Spec에 이름이 있는 간격 · 여백(예: 검색 필드 간격)은 컴포넌트 토큰(`search-area/item-gap`)으로 만들고,
컴포넌트 토큰은 새 값을 만들지 않고 `{space.16}`처럼 Scale을 가리킵니다.
컴포넌트 내부의 작은 조합 간격은 `t.$space-8`처럼 Scale을 바로 써도 됩니다.

```json
// tokens/custom/search.json
"ItemGap": { "$type": "dimension", "$value": "{space.16}" }
```

```scss
.row {
  gap: t.$search-area-item-gap; // → var(--kp-search-area-item-gap) → var(--kp-space-16)
}
```

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>간격 · 여백은 Scale 값(4의 배수 단계)에서 고른다</td>
      <td>
        <code>margin: 15px</code>처럼 Scale 밖의 값을 직접 쓴다 (Stylelint 경고)
      </td>
    </tr>
    <tr>
      <td>시안 Spec 값(검색 필드 간격 등)은 컴포넌트 토큰으로 만들어 Scale을 가리키게 한다</td>
      <td>컴포넌트 토큰에 Scale과 같은 값을 숫자(px)로 다시 적는다</td>
    </tr>
    <tr>
      <td>관계가 가까운 요소는 작은 값, 영역 구분은 큰 값</td>
      <td>모든 간격을 같은 값으로 맞춰 위계를 없앤다</td>
    </tr>
  </tbody>
</table>

## 확인 필요

Spacing 가이드의 Usage 범위와 컴포넌트 시안 측정값이 다른 곳이 있어, 현재는 **컴포넌트 시안 값**을 유지합니다.

- Container Padding 20 · 24 ↔ Page Layout GUI의 Section 카드(검색 조건 · 조회 결과) 안쪽 16, 한 줄 Section 12, Date Picker 패널 16
- Button group 12 · 16 ↔ 시안의 버튼 간격 8 (Search 초기화 · 조회, Modal Footer, Page Title Action, Button Tab)
- Icon–Text 8 ↔ Button 아이콘 간격 4 (Button Guide Spec)
