# Spacing

Gap(요소 사이 간격)과 Padding(요소 안쪽 여백)에 공통으로 쓰는 Spacing Scale입니다.
값은 Figma `space/*` 변수(`tokens/figma/space.json`)를 그대로 씁니다.

## 1. Spacing Scale

간격은 Scale(`t.$space-N`)을 씁니다. 시안 Spec에 이름이 있는 간격(예: 검색 필드 간격)은 컴포넌트 파일 맨 위에
SCSS 변수로 두고 Scale을 가리킵니다. 여러 컴포넌트가 함께 쓰는 값(`control/*` 등)만 토큰(`tokens/custom`)으로 둡니다.

```scss
// SearchArea.module.scss
$search-area-item-gap: t.$space-16; // 검색 필드 간격

.row {
  gap: $search-area-item-gap;
}
```

## 3-1. 컨트롤 사이 간격 (사용자 확정)

| 사이                                                                            | 간격 | 만드는 방법                                                        |
| ------------------------------------------------------------------------------- | ---- | ------------------------------------------------------------------ |
| 입력 + 버튼 (예: 예금주 [예금주 조회], 우편번호 [찾기])                         | 8    | `ControlGroup`으로 묶음 (`grow`: 입력이 남는 폭을 채움)            |
| 버튼 + 버튼 (같은 형태, 예: [추가] [삭제])                                      | 8    | `ControlGroup`                                                     |
| 칸 안 라벨 + 입력 (예: 휴대폰번호 [입력])                                       | 12   | FormTable 칸 기본 간격                                             |
| 형태가 다른 묶음 사이 (예: 이력조회 ↔ [추가][삭제])                             | 16   | 제목 줄 오른쪽 기본 간격(FormSection) · 묶음 안은 `ControlGroup` 8 |
| 버튼 세트 + 버튼 세트 (예: [정보일괄변경][키움저축계좌통지] ↔ [새로고침][저장]) | 16   | `<ControlGroup spacing="lg">` 안에 세트마다 `<ControlGroup>`       |

간격을 인라인 스타일(`style={{ display: 'flex', gap }}`)로 만들지 않는다 — 가로 세트는 항상 `ControlGroup`, 위아래로 쌓는 묶음(팝업 본문 영역 · 소제목 + 표)은 `Stack`(`gap` 0 · 4 · 8 · 12 · 16(기본) · 24, `as` div · section · span).

```tsx
<SectionHeading
  title="담당자 정보"
  actions={
    <>
      <TextButton>이력조회</TextButton>
      <ControlGroup>
        <Button size="sm" variant="neutral" appearance="line">추가</Button>
        <Button size="sm" variant="neutral" appearance="line">삭제</Button>
      </ControlGroup>
    </>
  }
/>
<FormTable.Cell>
  <ControlGroup grow>
    <TextField fullWidth value={holder} />
    <Button variant="neutral" appearance="line">예금주 조회</Button>
  </ControlGroup>
</FormTable.Cell>
```

## 4. Scale 밖의 값 (시안 측정)

컴포넌트 시안에서 Scale에 없는 값이 측정된 곳은 측정값을 그대로 둡니다. 새 컴포넌트에서는 Scale 값을 먼저 씁니다.

표의 이름은 `control/*` · `field/gap`처럼 공통 토큰이거나, 컴포넌트 파일의 SCSS 변수입니다(`lnb/indent` → `Lnb.module.scss`의 `$lnb-indent`).
크기(높이 · 아이콘 · 반경 · 선 두께)는 Spacing이 아니라 공통 `control/*` 토큰이나 컴포넌트 파일의 SCSS 변수로 관리합니다.

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>간격 · 여백은 Scale 값(4의 배수 단계)에서 고른다</td>
      <td>
        <code>margin: 15px</code>처럼 Scale 밖의 값을 직접 쓴다 (Stylelint 경고)
      </td>
    </tr>
    <tr>
      <td>
        시안 Spec 값(검색 필드 간격 등)은 컴포넌트 파일 맨 위 SCSS 변수로 두고 Scale을 가리키게 한다
      </td>
      <td>Scale과 같은 값을 숫자(px)로 다시 적거나, 선언에 값을 직접 쓴다</td>
    </tr>
    <tr>
      <td>관계가 가까운 요소는 작은 값, 영역 구분은 큰 값</td>
      <td>모든 간격을 같은 값으로 맞춰 위계를 없앤다</td>
    </tr>
  </tbody>
</table>

## 확인 필요

Spacing 가이드의 Usage 범위와 컴포넌트 시안 측정값이 다른 곳이 있어, 현재는 **컴포넌트 시안 값**을 유지합니다.

- Container Padding 20 · 24 ↔ Page Layout GUI의 Section 카드(검색 조건 · 조회 결과) 안쪽 16, 한 줄 Section 12, Date Picker 패널 16
- Button group 12 · 16 ↔ 시안의 버튼 간격 8 (Search 초기화 · 조회, Modal Footer, Page Title Action, Button Tab)
- Icon–Text 8 ↔ Button 아이콘 간격 4 (Button Guide Spec)
