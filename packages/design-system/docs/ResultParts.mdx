# Result Parts

조회 화면(페이지 패턴 P01 Search → Result)의 결과 영역 부품입니다. 구성 순서 · 상태 흐름은
**Patterns › P01 Search Result › Guide**를 따릅니다. 검색 조건 카드는 **Composites › Search › Search Panel**.

| 부품              | 용도                                                                         |
| ----------------- | ---------------------------------------------------------------------------- |
| `AppliedFilters`  | 조회에 사용한 조건 칩 (조회 전 안내)                                         |
| `ResultSummary`   | 조회 요약 수치 (값 1개 · 여러 개, 조회 전 `-`, 항목 `tone`으로 숫자 상태 색) |
| `ResultPanel`     | 조회 결과 카드 (제목 · Grid 공통 Action · 업무 Action · 상태 표시)           |
| `ResultFooter`    | Total + Pagination                                                           |
| `GridPlaceholder` | (임의 작업) IBSheet 연결 전 미리보기 표                                      |
