# Modal

업무 팝업입니다. **Header · Body · Footer**를 조합해 Alert · Confirm · Information · Form · Lookup을 만듭니다.
Close(X)는 이탈, Footer는 업무 처리입니다.

```tsx
import { Modal, Button } from '@kiwoompay/design-system';

<Modal open={open} onClose={() => setOpen(false)}>
  <Modal.Header title="확인" />
  <Modal.Body>
    <Modal.Description>입력한 항목을 저장할까요?</Modal.Description>
  </Modal.Body>
  <Modal.Footer>
    <Button size="lg" variant="neutral" appearance="line" onClick={() => setOpen(false)}>
      취소
    </Button>
    <Button size="lg" onClick={save}>
      저장
    </Button>
  </Modal.Footer>
</Modal>;
```

## 2. Action

버튼 개수는 Type과 분리해 필요한 처리 방식에 맞게 조합합니다: **None**(버튼 없음, Header X 또는 선택 즉시 종료) · **Single**(확인 등 단일 처리) · **Double**(취소 + 확인/저장).

### Form 본문 배치

- 필드 줄 간격 12, 필드 높이 40(md), 라벨 ↔ 필드 8(왼쪽) · 4(위).
- **조회 필드**(검색어 + [조회]): 검색 필드가 남은 폭을 채우고 [조회]는 `variant="neutral"` Solid, 간격 8.
  라벨은 위(`labelPosition="top"`) 또는 왼쪽 중 화면에 맞게 고릅니다.
- 그 밖의 입력(금액 · 비고 등)은 라벨 왼쪽 + 입력 폭 200, 날짜는 DateField 기본 폭.
- 버튼이 있으면 Footer 가운데 [취소(Neutral Line) + Primary], 버튼 크기 lg.

## 5. Close & Action Rule

- **Close(X)** = 현재 Modal 이탈. **취소** = Close(X)와 동일한 미저장 이탈 동작 → 둘 다 `onClose`로 처리합니다. `Esc`도 `onClose`를 호출합니다(`closeOnEsc`).
- **Primary Action** 성공 후 후속 입력이 없으면 Modal을 자동으로 닫습니다.
- 딤 영역 클릭으로는 기본적으로 닫히지 않습니다(입력 중 실수 방지). 필요하면 `closeOnDimClick`.
- Multi-select Lookup 예외: 여러 항목 선택 시 Header X 노출 / Footer [취소 + 적용]. [적용]은 선택 확정, [X · 취소]는 미적용 종료.
- API 실패 · 재시도 처리는 화면 설계와 개발에서 확인합니다.

## 6. Position

- 기준은 브라우저 전체 Viewport이며, 수평 · 수직 가운데 정렬을 유지합니다(화면 크기가 바뀌어도 유지).
- 딤은 LNB · Header를 포함한 전체 화면에 적용됩니다(`document.body`에 그립니다).
- 최소 안전 여백 상 · 하 · 좌 · 우 40. Modal이 열린 동안 배경 페이지 스크롤은 잠깁니다.

## 7. Scroll

- 최대 높이 `calc(100vh - 80px)`. 내용이 넘치면 **Body에만** 세로 스크롤이 생기고, 스크롤바는 Body 오른쪽에 표시됩니다.
- Header와 Footer는 고정이며, Footer Action은 스크롤 위치와 관계없이 항상 보입니다.
- 모달 끝에서 스크롤해도 배경으로 전달되지 않습니다(배경 스크롤 잠금).
- Modal이 닫히면 연 요소로 포커스가 돌아갑니다.
- Validation 오류가 나면 첫 오류 항목이 Body 안에 보이게 스크롤합니다. 오류 필드에는 `aria-invalid`가 붙으므로 아래처럼 처리합니다.

```tsx
const bodyRef = useRef<HTMLDivElement>(null);
// 검증 실패 후
bodyRef.current?.querySelector('[aria-invalid="true"]')?.scrollIntoView({ block: 'nearest' });

<Modal.Body ref={bodyRef}>…</Modal.Body>;
```
