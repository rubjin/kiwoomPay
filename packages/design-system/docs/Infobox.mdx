# Infobox

화면 안에 **항상 보이는 안내 문구**를 묶어 보여주는 상자입니다. 사용자가 닫거나 응답할 필요가 없는 정보(수정 불가 안내, 문의처, 조회 범위 등)에 씁니다.

## 1. 구성

```tsx
<Infobox tone="info">
  <Infobox.Item
    title="계정정보 변경 안내"
    actionLabel="변경 요청"
    action={
      <Infobox.Link href="mailto:pg-admin@daoudata.co.kr">pg-admin@daoudata.co.kr</Infobox.Link>
    }
  >
    휴대전화번호·이메일 등 기본 계정정보는 직접 수정할 수 없습니다.
  </Infobox.Item>
</Infobox>
```

| 요소                     | 설명                                                                    |
| ------------------------ | ----------------------------------------------------------------------- |
| `Infobox`                | 상자. `tone` info(파란 배경 · 기본) · neutral(회색 배경)                |
| `Infobox.Item`           | 한 줄: 아이콘 · 제목(`title`, 생략 가능) · 설명(children) · 오른쪽 영역 |
| `actionLabel` · `action` | 오른쪽 보조 문구와 링크 · 버튼. 둘 다 없으면 오른쪽 영역을 그리지 않음  |
| `icon`                   | 아이콘 바꾸기(기본 Info). `null`이면 숨김                               |
| `Infobox.Link`           | 오른쪽 끝 링크(Primary 13 Bold, Hover 밑줄)                             |

## 2. 규칙

### 톤 고르기 (사용자 확정)

| 안내 대상                                                                               | tone         | 배경                 | 테두리                |
| --------------------------------------------------------------------------------------- | ------------ | -------------------- | --------------------- |
| **화면 전체**에 대한 안내 (화면 상단 안내 등)                                           | `info`(기본) | #F0F7FC (Primary 50) | #BDDDF1 (Primary 200) |
| **표 · 섹션**에 대한 안내 (그 카드 안 맨 아래 — 표 아래 · 영역 안내, 팝업 안 처리 안내) | `neutral`    | #F8FAFC (Neutral 50) | #D5DCE5 (Neutral 300) |

- 글자는 두 톤 같음: 설명 13 Regular #435064(Neutral 700), 제목 13 SemiBold #111827(Neutral 900), 제목 ↔ 설명 8

### 배치 · 나열

- 여러 줄을 넣으면 **제목 · 설명 열이 맞춰집니다**(가장 긴 제목 기준).
- 오른쪽 영역은 항상 오른쪽 끝에 붙고 줄바꿈하지 않습니다. 폭이 좁으면 설명이 줄바꿈됩니다.
- 상자 폭은 부모를 채웁니다.
- 제목 없이 안내 문장만 있으면 `title`을 생략합니다 — 설명이 아이콘 바로 옆부터 이어집니다(화면 상단 안내 · 팝업 안내).
- **같은 내용(제목 없는)의 안내가 여러 개면 점 목록** — `<Infobox.Item bullets={[…]} />` 하나, 톤은 위 표대로(표 · 섹션 안내면 `neutral`). Info 아이콘은 하나, 각 안내는 점(•)으로 (기준: 정산원장 일괄 처리 팝업 `LedgerActionModal` notices). 제목 없는 `Infobox.Item`을 여러 개 쓰지 않습니다(아이콘이 줄마다 반복됨). 제목이 있는 안내(`title`)만 줄마다 `Infobox.Item`.

```tsx
<Infobox tone="neutral">
  <Infobox.Item
    bullets={[
      '미사용 메뉴는 권한 보유와 관계없이 미노출 및 직접 접근 차단',
      '3Depth 메뉴에 사용 이력이 있으면 삭제 불가, 미사용 처리',
    ]}
  />
</Infobox>
```

## 3. Spec

- 높이: 한 줄 46 · 두 줄 74 (위아래 여백 12 · 줄 높이 20 · 줄 간격 8)
- 좌우 여백 16 · 반경 8 · 테두리 1
- 간격 8: 아이콘 20(`info-box`) ↔ 제목 ↔ 설명 ↔ 오른쪽 영역(최소), 라벨 ↔ 링크, 제목 ↔ 아래 점 목록
- 글자: 제목 `typo-13-semi-bold` · 설명 · 점 목록 `typo-13-regular` · 라벨 `typo-12-regular` · 링크 `typo-13-bold`
- 색: `infobox/*` (`tokens/custom/infobox.json`, 모두 alias) — Info 배경 Primary 50 · 테두리 Primary 200, Neutral 배경 `Bg/Page`(Neutral 50) · 테두리 `Line/Default`(Neutral 300), 아이콘 `Text/Body` · 제목 `Text/Heading`(#111827) · 설명 `Text/Label`(#435064) · 라벨 `Text/Label` · 링크 `Text/Accent`
- 크기 · 간격은 `Infobox.module.scss` 맨 위 SCSS 변수

## 4. Do / Don't

- ✅ 화면을 이용하는 동안 계속 알아야 하는 안내
- ✅ 같은 성격의 안내 여러 개는 한 상자에 묶기 — 제목 없으면 `bullets`(아이콘 하나 + 점 목록)
- ✅ 톤은 대상으로 고르기 — 화면 전체 `info` · 표 · 섹션 `neutral`
- ❌ 제목 없는 `Infobox.Item`을 여러 개 나열 — 아이콘이 줄마다 반복됩니다
- ❌ 저장 결과 · 오류처럼 일시적인 알림 — Toast · Modal을 씁니다
- ❌ 페이지 상단 공지 · 점검 안내 — Page Notice를 씁니다
- ❌ 긴 본문(여러 문단) — 설명은 한두 문장으로
- ✅ **표 · 섹션에 대한 안내는 그 카드 안 맨 아래**(`neutral`) — `PageLayout.Section`은 마지막 자식, `ResultPanel`은 `footer`(여백 16). 화면 전체 안내(`info`)는 카드 밖 위 (사용자 결정, 2026-11-18 — 직전 "카드 밖" 규칙 대체). **카드에 내용이 없으면(선택 전 · 0건 · 오류 — StatusView만) 안내도 넣지 않는다**
