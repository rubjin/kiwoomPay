# P02 Record → Form

한 업무 대상을 **조회 · 등록 · 수정**하는 화면의 골격입니다 (Figma Pattern Library P02).
기준 화면: KWPC07010101 가맹점 기본/계약 정보 관리 (신규등록 · 조회수정).

## 1. 구성

| 순서 | 부품                                                 | 내용                                                                                                 |
| ---- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 1    | `PageLayout.Title` + `titleAddon`                    | 화면명 + 현재 대상(ContextChip) · 상태 Badge (조회수정)                                              |
| 2    | `FormSection` (`tabs` · `tabActions` · `underTitle`) | 제목 탭(정보 묶음) + [새로고침] · [등록/저장], 기본 정보 카드(접기). 화면명 바로 아래면 `underTitle` |
| 3    | `FormTable`                                          | 라벨-값 표 (4쌍), 주소 등 여러 입력은 `colSpan` + `InlineLabel`                                      |
| 4    | `SectionHeading` + 목록형 `FormTable`                | 담당자 정보처럼 행을 추가 · 삭제하는 표                                                              |
| 5    | `FormSection` (`heading` = `SectionHeading` label)   | 하위 대상(선택 CPID)과 탭 · 접기                                                                     |

- 제목 줄은 모두 **`SectionHeading`** 입니다 — 화면명 `xl`(24), 카드 제목(`FormSection heading`) · 본문 중간 제목 · 대상 표시(선택 CPID) `lg`(18). 화면 코드에서도 `<SectionHeading>`을 직접 씁니다. 한 카드 안의 제목은 같은 크기
- 탭 묶음 위 간격은 `FormSection`이 맞춥니다 — 화면에서 `marginTop`으로 보정하지 않습니다

## 2. 모드

- **등록(create)**: 빈 값, 저장 버튼 [등록], 하위 대상 영역은 접힘(대상 없음)
- **수정(edit)**: 조회 값, 저장 버튼 [저장], 제목 옆 현재 대상 · 상태, 바꿀 수 없는 키(사업자번호)는 읽기 전용 + [수정] 팝업
- **조회 전용(read)**: 값을 텍스트로 (페이지 패턴 P-5)

## 3. 저장 흐름 (P04)

1. 필수 입력 확인 → 없으면 `dialog.alert`
2. `dialog.confirm('… 등록할까요?')`
3. 저장 중 버튼 로딩 → 결과 `dialog.alert` (Toast 없음)
