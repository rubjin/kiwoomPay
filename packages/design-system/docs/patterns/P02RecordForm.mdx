# P02 Record → Form

한 업무 대상을 **조회 · 등록 · 수정**하는 화면의 골격입니다 (Figma Pattern Library P02).
기준 화면: KWPC07010101 가맹점 기본/계약 정보 관리 (신규등록 · 조회수정).

## 1. 구성

| 순서 | 부품                                                 | 내용                                                                                       |
| ---- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 1    | `PageLayout.Title` + `titleAddon`                    | 화면명 + 현재 대상(ContextChip) · 상태 Badge (조회수정)                                    |
| 2    | `FormSection` (`tabs` · `tabActions` · `underTitle`) | 박스: 제목 탭(정보 묶음) + [새로고침] · [등록/저장], 접기. 화면명 바로 아래면 `underTitle` |
| 3    | `FormGroup` (`SectionHeading` + `FormTable`)         | 라벨-값 표 (4쌍), 주소 등 여러 입력은 `colSpan` + `InlineLabel`                            |
| 4    | `FormGroup` (`SectionHeading` + 목록형 `FormTable`)  | 담당자 정보처럼 행을 추가 · 삭제하는 표                                                    |
| 5    | `FormSection` > `FormGroup` (`SectionHeading` label) | 하위 대상(선택 CPID)과 탭 · 접기                                                           |

- 제목 줄은 모두 **`SectionHeading`** 입니다 — 화면명 `xl`(24), 카드 제목 · 담당자 정보 · 대상 표시(선택 CPID) `lg`(18). 박스(`FormSection`) 안에 "제목 + 폼" 묶음(`FormGroup`)으로 넣고, 접기는 첫 제목 줄 `actions`의 `<FormSection.Toggle />`. 한 카드 안의 제목은 같은 크기
- 탭 묶음 위 간격은 `FormSection`이 맞춥니다 — 화면에서 `marginTop`으로 보정하지 않습니다

## 2. 모드

- **등록(create)**: 빈 값, 저장 버튼 [등록], 하위 대상 영역은 접힘(대상 없음)
- **수정(edit)**: 조회 값, 저장 버튼 [저장], 제목 옆 현재 대상 · 상태, 바꿀 수 없는 키(사업자번호)는 읽기 전용 + [수정] 팝업
- **조회 전용(read)**: 값을 텍스트로 (페이지 패턴 P-5)

## 3. 저장 흐름 (P04)

1. 필수 입력 확인 → 없으면 `dialog.alert`
2. `dialog.confirm('… 등록할까요?')`
3. 저장 중 버튼 로딩 → 결과 `dialog.alert` (Toast 없음)

## 4. 조회 전용 상세 팝업 (V01)

목록에서 한 건을 골라 정보만 보여 주는 팝업입니다 (Figma KWPC04010101 거래 상세정보 · PG — 기본정보 · 결제정보). 입력 · 저장이 없으므로 Footer가 없습니다. 폭은 Modal md 620(Figma 520 → 가까운 표준 크기), 높이는 가장 긴 탭 기준으로 고정(`height`) — 탭을 바꿔도 팝업 크기가 같고, 넘치면 본문만 스크롤.

| 순서 | 부품                                           | 규격                                                                                                                                                                                                                                                                      |
| ---- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | `Modal.Header`                                 | 제목 20 SemiBold + 닫기                                                                                                                                                                                                                                                   |
| 2    | `DetailTarget`                                 | "선택한 거래" 12 Regular + 값 13 SemiBold Accent, 사이 16 · 아래 구분선 (스크롤 밖)                                                                                                                                                                                       |
| 3    | `DetailTabs` + `Tab variant="title" fullWidth` | 탭이 폭을 나눠 가짐 (스크롤 밖)                                                                                                                                                                                                                                           |
| 4    | `DetailSection`                                | `SectionHeading` md(16 Bold) + 설명 12, 카드 사이 12                                                                                                                                                                                                                      |
| 5    | `DetailCard`                                   | Neutral 50 · 테두리 · 반경 6 · 여백 12, 제목 14 Bold, 라벨 12 SemiBold(폭 73) · 값 12 Regular, 2열(카드 폭을 똑같이 나눔, 한 줄 전체는 `span: 2`) · 줄 사이 16, 값 없으면 "-", 오류 값은 항목 `tone: 'error'`(Chart/Negative 빨간 글자), 항목이 없으면 `emptyText` 가운데 |

## 5. 조회 + 입력 팝업

선택한 거래의 정보를 보면서 처리 내용을 등록하는 팝업입니다 (Figma KWPC04010101 고객문의·민원 처리). 폭은 Modal md 620(Figma 720 → 가까운 표준 크기).

- `DetailTarget divider={false}`: 탭 없이 바로 카드가 오면 구분선 없음
- 정보 카드: `DetailCard labelGap={20}` — 이름이 긴 항목(CP상담전화 · 메일 발송여부)이 있으면 이름 ↔ 값 20
- 표 카드: `DetailCard`의 children으로 표(IBSheet 연결 전에는 `GridPlaceholder`, 행이 없으면 `empty` 글자 → 한 줄 가운데 안내)
- 입력 폼 카드: `DetailCard form` — 값 자리에 SelectBox · TextField · DateField(`fullWidth`), 열 사이 40 · 이름 ↔ 컨트롤 20, 한 줄 전체는 `span: 2`
- Footer: `Modal.Footer start={새로고침}` — 왼쪽 끝 입력 초기화, 오른쪽 [취소] · [등록 후 메일 발송](Primary Line) · [등록](Primary), 모두 lg 48
- 등록: P04 `useAction`(필수 항목 안내 → 처리 → 닫기 · 완료 안내). 입력한 내용이 있으면 닫을 때 확인
