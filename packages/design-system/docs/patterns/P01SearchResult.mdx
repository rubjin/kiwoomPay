# P01 Search → Result

조건 검색부터 결과 확인 · 선택 처리까지 반복되는 조회 화면의 골격입니다 (Figma Pattern Library P01).
화면 시안이 없어도 **이 순서와 부품**으로 만들고, 화면설계서의 필드 · 컬럼 · 버튼만 채웁니다.

- 기준 화면: KWPC06010201 가맹점 정산 실행/처리 (최초진입 · 조회결과), KWPC04010100 통합 거래내역 (최초진입 · 검색 조건 접힘)
- 업무 조건(필드 · 컬럼 · 집계 · 처리 가능 상태 · 권한)은 화면설계서를 따르고, 패턴은 정하지 않습니다.

## 1. 구성 순서

| 순서 | 부품                           | 필수      | 내용                                                                             |
| ---- | ------------------------------ | --------- | -------------------------------------------------------------------------------- |
| 1    | `PageLayout.Title`             | ●         | 화면명 + 오른쪽 내 검색조건 선택 · 관리(P07)                                     |
| 2    | `SearchPanel`                  | ●         | 제목 줄 [초기화 ↻] · [조회], 구분선 아래 기본 조건, 아래 붙은 카드 [상세 검색 ⌄] |
| 3    | `AppliedFilters`               | 옵션(V04) | 조회에 **사용한** 조건 칩. 조회 전 안내 문구                                     |
| 4    | `ResultSummary`                | 옵션(V04) | 집계 건수. 조회 전 `-`                                                           |
| 5    | `ResultPanel` + Grid(IBSheet8) | ●         | 제목 옆 표시항목설정 · 엑셀, 오른쪽 업무 Action(V05). 행이 없으면 `StatusView`   |
| 6    | `ResultFooter` + `Pagination`  | ●         | 왼쪽 Total, 가운데 Pagination                                                    |

## 2. 흐름 — `useSearchResult`

```tsx
const result = useSearchResult({ initialParams, fetch: api.fetchList }); // autoSearch 기본 false

<SearchPanel onSearch={result.search} onReset={result.reset} loading={result.loading}>
  <Field label="CPID"><TextField value={result.params.cpid} onChange={(e) => result.setParam('cpid', e.target.value)} /></Field>
</SearchPanel>
<AppliedFilters items={toFilters(result.appliedParams)} />
<ResultSummary items={toSummary(result.summary)} />
<ResultPanel status={result.status} actions={…}>{grid}</ResultPanel>
<ResultFooter total={result.total}>
  <Pagination totalPages={result.totalPages} page={result.page} onChange={result.setPage} />
</ResultFooter>
```

- **입력 조건(`params`)과 조회 조건(`appliedParams`)을 분리**합니다. 조건을 바꿔도 [조회] 전까지 결과 · 적용 조건 칩은 그대로입니다.
- [초기화]는 입력 조건만 기본값으로 되돌립니다(결과는 유지).
- 페이지 이동은 마지막으로 조회한 조건으로 다시 조회합니다. 늦게 온 이전 응답은 버립니다.
- 처리 · 저장 후 목록 갱신은 `await result.refresh()` — 같은 조건 · 같은 페이지로 재조회하고, 행이 빠져 현재 페이지가 비면 마지막 페이지로 옮깁니다. 완료 Alert는 재조회 뒤에 띄웁니다.
- `status`: `idle`(조회 전) · `loading` · `success` · `empty`(0건) · `error` · `forbidden`(`isForbidden`으로 판별)

### 검색 조건 배치

- 필드가 두 줄 이상이면 `SearchPanel.Row`로 줄을 나눈다 (줄 = 전체 폭, 줄 사이 16). 한 줄 안에서 `flex`로 남는 폭을 채운다
- 상세 검색을 펼치면 영역 배경이 Primary 50 (`search-result/detail-bg`)
- 처음부터 접어 둘 화면은 `defaultCollapsed` (KWPC04010100 최초진입): 제목 줄만 보이고 상세 검색 줄도 숨긴다
- 직접 입력 + 팝업 찾기 필드는 `LookupField`(검색 아이콘 + [찾기], P03). 팝업을 취소하면 값은 그대로
- 라디오처럼 낮은 컨트롤도 `Field` 안에서 라벨 줄(40) 가운데에 맞는다
- 조회 요약 항목에 값이 여러 개면 `values` (예: `- 건 • - 원`)
- 결과 제목 줄 오른쪽에 `ActionBar`(예: 취소사유 입력 + 선택 취소)를 넣을 수 있다 (`style={{ flex: '1 1 0' }}`)

### 검색 조건 폼 정리 (내 검색조건 저장 · 불러오기 대비)

내 검색조건 관리(저장 · 적용 · 요약)가 있으므로 검색 조건은 **값(params) · 기본값 · 정의**로 나눠 둡니다.

1. **params**: JSON으로 저장할 수 있는 평면 객체 (문자열 · 문자열 배열 · boolean). 날짜 `YYYY-MM-DD`, 시각 `HH:mm`, 전체 `'all'`
2. **기본값** `INITIAL_PARAMS`: [초기화] · 신규 저장 기준
3. **정의** `SearchFieldDef[]`: `key · label · group(basic | detail) · format(params) · applied`
   - `toAppliedFilters(defs, appliedParams)` → 적용된 검색 조건 칩
   - `summarizeSearch(defs, params)` → 내 검색조건 요약(조회기준일 · 조회기간 · 조회일시 …)
   - `applied: false`: 저장 요약에만 보이는 항목 (예: 조회기준일, 퀵 기간 이름)
   - `format`이 `null`이면 표시하지 않음 (빈 입력, 기본값과 같은 체크 등)

| 유형      | 컴포넌트                                                 | 예                            | 값                            | 칩 표시                            |
| --------- | -------------------------------------------------------- | ----------------------------- | ----------------------------- | ---------------------------------- |
| 텍스트    | `TextField`                                              | 거래번호 · 고객명             | `string`                      | 비면 숨김 (`textValue`)            |
| 찾기      | `LookupField`                                            | 사업자번호 · CPID             | `string`                      | 비면 숨김                          |
| 단일 선택 | `SelectBox`                                              | 거래구분 · 결제수단           | `string` (`'all'`)            | 이름 (`optionLabel`) — 전체도 표시 |
| 다중 선택 | `MultiSelect`                                            | 정산주기                      | `string[]`                    | 쉼표 나열, 비면 전체               |
| 라디오    | `RadioGroup`                                             | 조회기준일 · 거래원천         | `string`                      | 이름                               |
| 체크      | `Checkbox`                                               | 개인정보 포함 검색            | `boolean`                     | 기본값과 다를 때만                 |
| 기간      | `DateRangeField` 또는 `DateField` + 시각 `SelectBox` × 2 | 지급예정일 · 조회기간         | 날짜 · 시각 각각              | `시작 ~ 종료` 한 칩                |
| 퀵 기간   | `Segmented size="md"`                                    | 1주일 · 1개월 · 2개월 · 3개월 | `'1w'` … (직접 수정하면 `''`) | 저장 요약에만                      |

- 상세 검색 필드는 `group: 'detail'`. 상세 검색을 접어도 값은 유지되고 조회에 쓰인다
- 결과 제목 줄의 `ActionBar`(취소사유 등)는 **행을 선택해야 활성** (Figma 목록 · 상세검색)

## 3. 상태 (화면 체크리스트)

| 상태      | 결과 영역                                 | Action                       |
| --------- | ----------------------------------------- | ---------------------------- |
| 최초 진입 | 조회 전(`idle`), 요약 `-`, 적용 조건 안내 | 결과 Action 비활성           |
| 조회 중   | [조회] 로딩 · 중복 실행 차단              | —                            |
| 결과      | Grid · Total · Pagination                 | 활성                         |
| 0건       | `조회 결과가 없습니다`                    | 비활성                       |
| 오류      | `조회 중 오류가 발생했습니다`             | 비활성. 필요하면 [다시 시도] |
| 권한 없음 | `조회 권한이 없습니다`                    | 비활성                       |

## 4. 선택 + 업무 Action (V05)

Grid 체크박스로 대상을 고르고 오른쪽 업무 Action을 누릅니다. 처리 흐름은 P04(Action → Feedback)입니다.

1. 선택이 없으면 `dialog.alert('처리할 … 선택해주세요.')`
2. `dialog.confirm('선택한 … N건을 … 처리할까요?')`
3. 처리 중 버튼 비활성 → 결과는 **Alert로 안내**(Toast 없음) → 같은 조건으로 다시 조회

```tsx
const dialog = useDialog(); // 앱 최상위에 <DialogProvider>
```

## 5. 기본값 (시안이 없을 때)

- 검색 필드: `Field`(라벨 왼쪽 · 간격 8) + md 40. 필드 사이 16, 넘치면 줄바꿈. 한 칸을 `flex`로 늘려 줄을 채움
- 기간 퀵 버튼: `Segmented size="md"`(1주일 · 1개월 · 2개월 · 3개월), 날짜를 직접 바꾸면 선택 해제
- 결과 Action: Grid 공통(표시항목설정 · 엑셀)은 제목 옆 Neutral Line sm, 업무 Action은 오른쪽 — 보조 Neutral Line · 주의 Dark · 등록 Primary(+ 아이콘)
- 숫자: 천 단위 쉼표, 빈 값 `-`
