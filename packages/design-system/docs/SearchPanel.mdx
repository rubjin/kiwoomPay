# Search Panel

조회 화면(페이지 패턴 P01 Search → Result)의 검색 조건 카드입니다. 구성 순서 · 상태 흐름 · 검색 조건 정리는
**Patterns › P01 Search Result › Guide**를 따릅니다. 결과 영역 부품은 **Composites › Result › Result Parts**.

| 부품               | 용도                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| `SearchPanel`      | 검색 조건 카드: 제목 · 접기, [초기화 ↻] · [조회], 기본 조건, 아래 붙은 [상세 검색] |
| `SearchPanel.Row`  | 필드 줄 나누기 (한 줄 = 전체 폭)                                                   |
| `SearchPanel.Grid` | 같은 폭 N칸 격자 (상세 검색 5칸)                                                   |

- 필드는 `Field`(라벨 왼쪽 · 간격 8) + md 40, 필드 사이 16
- 상세 검색을 펼치면 영역 배경 Primary 50, 접어도 값은 유지
- `defaultCollapsed`: 제목 줄만 (상세 검색 줄도 숨김)
- `variant="box"`: **팝업 안 조회 조건** — 제목(md 16)은 상자 밖 위(사이 16), 회색 상자(Neutral 50 · 여백 16) 안에 필드 한 줄 + 끝에 [초기화] · [조회](Primary). 접기 · 상세 검색 없음 (Figma 마이페이지 권한 신청 현황 팝업)
- `actionsPlacement="inline"`: 조건이 한 줄뿐인 화면(다운로드 센터) — [초기화] · [조회]를 필드 줄 끝에 두고, 제목 16 · 제목 줄 32 · 접기 없음. 남는 폭은 마지막 필드(`flex`)가 채운다
