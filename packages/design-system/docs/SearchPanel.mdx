# Search Panel

조회 화면(페이지 패턴 P01 Search → Result)의 검색 조건 카드입니다. 구성 순서 · 상태 흐름 · 검색 조건 정리는
**Patterns › P01 Search Result › Guide**를 따릅니다. 결과 영역 부품은 **Composites › Result › Result Parts**.

| 부품               | 용도                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| `SearchPanel`      | 검색 조건 카드: 제목 · 접기, [초기화 ↻] · [조회], 기본 조건, 아래 붙은 [상세 검색] |
| `SearchPanel.Grid` | 같은 폭 N칸 격자 (상세 검색 5칸)                                                   |

- 필드는 `Field`(라벨 왼쪽 · 간격 8) + md 40, 필드 사이 16
- **필드 흐름**(사용자 확정): 필드를 순서대로 나열한다 — 폭이 남으면 다음 줄 필드가 위 줄로 올라오고, 길어지면 다음 줄로 내려간다. 줄을 강제로 나누는 `SearchPanel.Row`는 삭제(2026-11-16), 필드를 `flex`로 늘려 줄을 채우지 않는다
- **기본 폭**(사용자 확정): 폭을 정하지 않은 입력(TextField) · 셀렉트(SelectBox · MultiSelect)는 **200**, 앞에 검색 아이콘이 있는 입력(SearchField · LookupField)은 **228**, 날짜(DateField)는 **140**. `fullWidth`나 직접 준 폭이 우선하고, 기간(DateRangeField)은 **264** 고정(검색 조건 밖에서도, 2026-11-17). SearchPanel이 `--field-default-width` · `--search-field-default-width` · `--date-field-default-width`로 내려 주므로 검색 조건 밖(팝업 · 표)은 지금처럼 내용 폭
- **기간 + 퀵 기간은 한 묶음**: 기간 필드(`DateRangeField`)와 퀵 기간(`Segmented`)은 같은 `Field` 안에 `ControlGroup`으로 묶는다(사이 8) — 따로 두면 필드 사이 16이 되고 줄이 바뀔 때 떨어진다
- **퀵 기간(Segmented md)**(사용자 확정): 옵션 하나 최소 폭 **55**, 검색 조건 안에서는 **늘어나지 않음** — `fullWidth`를 줘도 내용 폭(SearchPanel이 `--segmented-item-min-width` · `--segmented-full-width` · `--segmented-item-flex`로 막음). 검색 조건 밖은 그대로(최소 60, fullWidth면 늘어남)
- 상세 검색을 펼치면 영역 배경 Primary 50, 접어도 값은 유지
- `defaultCollapsed`: 제목 줄만 (상세 검색 줄도 숨김)
- `fieldWidth`: 안의 입력 · 셀렉트 기본 폭. `md`(기본) 200 · `lg` 270(사용자 확정). 앞 검색 아이콘 입력은 +28(228 · 298), 날짜 · 기간(264)은 그대로
- `variant="plain" actionsPlacement="header"`: 팝업 조회 조건의 필드가 여러 줄일 때 — 제목 줄 오른쪽 끝에 [초기화] · [조회], 필드는 아래 `SearchPanel.Grid`(같은 폭 칸, 칸을 채우도록 `fullWidth`). plain의 기본 버튼 위치는 필드 줄 끝(inline) (Figma 정산원장 찾기 팝업)
- `variant="plain"`: **팝업 안 조회 조건 전용(사용자 결정)** — 화면 본문은 카드(기본), 팝업은 항상 plain + `fieldWidth="lg"`. 필드 줄 사이 12(칸 사이는 16). — 카드 · 상자 없이 제목(md 16) 아래(사이 16) 필드 한 줄 + 끝에 [초기화] · [조회](다른 검색 조건과 같은 Neutral). 접기 · 상세 검색 없음. 팝업 조회 조건은 `fieldWidth="lg"`(입력 · 셀렉트 270) — 인라인 폭을 주지 않는다
- `actionsPlacement="inline"`: 조건이 한 줄뿐인 화면(다운로드 센터) — [초기화] · [조회]를 필드 줄 끝에 두고, 제목 16 · 제목 줄 32 · 접기 없음. 남는 폭은 마지막 필드(`flex`)가 채운다
