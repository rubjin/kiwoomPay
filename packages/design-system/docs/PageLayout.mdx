# Page Layout

조회형 화면의 공통 영역 구성과 배치 기준입니다. 가로 1920px 기준, 세로는 구조만 정합니다.
Page Layout은 **화면 영역 · 배치 기준만** 정의하고, Grid 기능 · 업무별 컬럼 · 데이터 처리 로직과 분리합니다.

```tsx
import { PageLayout, Lnb, WorkTab } from '@kiwoompay/design-system';

<PageLayout
  lnb={<Lnb items={menu} activeId={menuId} />}
  header={<AppHeader />}
  workTab={<WorkTab value={tabId} onChange={go} onClose={close}>…</WorkTab>}
  workTabActions={<WorkTab.ActionMenu count={tabs.length} actions={tabActions} />}
  footer={<AppFooter />}
>
  <PageLayout.Title title="통합 거래내역" actions={<Button>내 검색조건 관리</Button>} />
  <PageLayout.Section title="검색 조건" divider>
    <SearchArea …>…</SearchArea>
  </PageLayout.Section>
  <PageLayout.Section title="적용된 검색 조건" layout="inline" compact>…</PageLayout.Section>
  <PageLayout.Section title="조회 결과" titleAddon={…} actions={…}>
    {/* IBSheet8 Grid */}
  </PageLayout.Section>
</PageLayout>;
```

## 3. Search State Behavior

- 상세검색은 Search Area 내부에서 확장합니다. 아래 영역의 순서 · 너비는 유지하고 **높이만 아래로 이동**(Push Down)합니다.
- 예시(통합 거래내역)에서 [상세조건]을 눌러 확인할 수 있습니다. 별도 처리 없이 문서 흐름으로 밀려 내려갑니다.
- 상세검색 확장 시 아래 영역은 재배치 · 겹침 없이 개별 Section을 유지합니다.

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Section 순서(검색 → 적용 조건 → 요약 → 결과)를 지킨다</td>
      <td>화면마다 Section 순서 · 간격을 바꾼다</td>
    </tr>
    <tr>
      <td>선택 영역(적용된 검색 조건 · 조회 요약)은 필요할 때만 넣는다</td>
      <td>빈 Section을 자리만 차지하게 둔다</td>
    </tr>
    <tr>
      <td>Grid 높이 · 스크롤 · 고정 컬럼은 IBSheet8 설정으로 처리한다</td>
      <td>Page Content에 고정 높이를 주어 본문과 Grid가 이중 스크롤되게 만든다</td>
    </tr>
    <tr>
      <td>여백은 Section · Title 컴포넌트에 맡긴다</td>
      <td>Section 사이에 margin을 직접 넣는다</td>
    </tr>
  </tbody>
</table>

## 토큰 · 확인 필요

- 색: `page-layout/*` (`tokens/custom/page-layout.json`, 모두 Semantic alias). 높이 · 여백은 `PageLayout.module.scss` 맨 위 SCSS 변수. (`Bg/Page` Neutral 50 · `Bg/Surface` 흰색 확정)
- 반응형(가맹점관리자 모바일 · 태블릿)은 시안이 없어 적용하지 않았습니다
- Header · Footer 내용은 각 컴포넌트(시안 대기)로 제공 예정이며, 이 예시는 자리 표시입니다
- Header · Work Tab 스크롤 고정(sticky) 여부는 시안에 없어 본문과 함께 스크롤됩니다
- 실제 GUI의 검색 조건 카드는 제목 줄 오른쪽에 [새로고침] · [조회], 아래에 [상세 검색 ⌄]가 있어 Search 가이드(필드 줄 끝 버튼)와 배치가 다릅니다 — 확인 필요
- 적용된 검색 조건 칩 · 조회 요약 카드는 Data Display 가이드에서 만들 예정입니다(예시는 자리 표시)
