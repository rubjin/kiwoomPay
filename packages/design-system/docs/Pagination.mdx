# Pagination

데이터 목록의 페이지 이동을 위한 기본 페이지네이션입니다.
**이전 → 번호 → 생략(…) → 다음** 순으로 구성하며, 현재 페이지는 Active 상태로 표시합니다.

```tsx
import { Pagination } from '@kiwoompay/design-system';

const [page, setPage] = useState(1);
const totalPages = Math.ceil(totalCount / pageSize); // 페이지 단위·총 건수는 화면에서 계산

<Pagination
  totalPages={totalPages}
  page={page}
  onChange={(next) => {
    setPage(next);
    fetchList(next);
  }}
/>;
```

## 2. Structure

<Canvas of={PaginationStories.Structure} />

- 처음·끝 번호와 현재 번호 양옆 1개를 항상 보여주고, 사이가 비면 생략(…)합니다. 보이는 칸 수가 일정해서 이동해도 폭이 크게 흔들리지 않습니다.
- 노출 범위는 `siblingCount`(현재 양옆, 기본 1) · `boundaryCount`(처음·끝, 기본 1)로 조정합니다.

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>목록 아래 가운데에 하나만 둔다</td>
      <td>한 목록에 페이지네이션을 위 · 아래 두 개 둔다</td>
    </tr>
    <tr>
      <td>
        페이지를 바꾸면 목록을 다시 조회하고, 조회 중에는 <code>disabled</code>로 막는다
      </td>
      <td>조회 중에도 연속으로 눌러 요청이 겹치게 둔다</td>
    </tr>
    <tr>
      <td>결과가 1페이지 이하면 그대로 두거나 숨기는 기준을 화면 정책으로 정한다</td>
      <td>화면마다 숨김 기준을 다르게 처리한다</td>
    </tr>
    <tr>
      <td>필터·검색 조건이 바뀌면 1페이지로 돌아간다</td>
      <td>조건이 바뀌었는데 이전 페이지 번호를 유지해 빈 목록을 보여준다</td>
    </tr>
  </tbody>
</table>
