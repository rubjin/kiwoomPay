# Icon

시스템 아이콘 컴포넌트입니다. 동일한 시각 언어를 유지하기 위해 **Figma에서 내보낸 SVG만** 사용하고,
임의로 크기를 조절하지 않고 제공된 **Size variant**를 사용합니다. 시스템 아이콘의 기준 크기는 24px입니다.

```tsx
import { Icon } from '@kiwoompay/design-system';

<Icon name="search" size={20} />
<Icon name="download" size={16} aria-label="다운로드" />   {/* 텍스트 없이 단독으로 쓰면 aria-label */}

<span style={{ color: 'var(--kp-color-text-secondary)' }}>
  <Icon name="info-circle" size={16} />                      {/* 색은 부모의 color를 따른다 */}
</span>
```

- 크기마다 따로 그려진 variant를 씁니다. 모든 아이콘이 네 가지 크기를 가진 것은 아니어서, **요청한 크기의 variant가 없으면 가장 가까운 큰 variant를 줄여서** 그립니다. 이때 선 두께도 함께 줄어듭니다.
- 어떤 크기가 직접 제공되는지는 아래 갤러리의 숫자(예: `12 · 16 · 24`)로 확인합니다. `getIconSizes(name)`으로도 얻을 수 있습니다.
- 크기가 다르면 모양이 다른 아이콘이 있습니다 (예: `filter` 16 = 깔때기, 24 = 슬라이더).

## 3. Color

- **선 아이콘**은 색을 정하지 않고 글자색(`currentColor`)을 따릅니다. 부모 요소의 `color`로 사용 위치와 상태에 맞는 색을 줍니다. (Button 안에서는 버튼 글자색을 그대로 따릅니다.)
- **상태 아이콘**만 고유한 색을 가지며, 모두 토큰 변수로 연결되어 있습니다.

### 화이트 버전

화이트 아이콘은 별도로 두지 않습니다. 어두운 배경(헤더, 색 버튼 등)에서는 부모의 `color`를 흰색(`--kp-color-text-inverse`)으로 주면 선 아이콘이 모두 흰색이 됩니다. 상태 아이콘은 고유한 색을 유지합니다. 아래 갤러리에서 **어두운 배경**을 켜면 전체 아이콘을 화이트로 확인할 수 있습니다.

> Figma에서 내보낸 원본 SVG(`src/assets/icons/Name=….svg`)는 선이 흰색이라 흰 배경의 파일 미리보기에서는 비어 보입니다. 정상이며, 코드에서는 `currentColor`로 바뀝니다.

## 접근성과 사용

- 텍스트 라벨과 함께 쓰는 아이콘은 장식이므로 아무것도 주지 않습니다 (`aria-hidden`이 자동으로 붙습니다).
- 텍스트 없이 아이콘만 쓰는 버튼에는 `Button`의 `aria-label`을 주고, 아이콘 자체에 `aria-label`을 주면 `role="img"`가 됩니다.
- 아이콘은 `svg`라서 `className` · `style`과 SVG 속성을 그대로 전달할 수 있습니다. 색·크기는 `color`와 `size`로 정하고, `width` · `height`로 직접 덮어쓰지 않습니다.

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>영역에 맞는 크기를 고른다 (인풋 20, 헤더 24 …)</td>
      <td>
        <code>style</code>로 임의의 크기(18, 22 …)를 만든다
      </td>
    </tr>
    <tr>
      <td>
        색은 부모의 <code>color</code>로 정한다
      </td>
      <td>
        선 아이콘에 <code>stroke</code>로 고정색을 준다
      </td>
    </tr>
    <tr>
      <td>
        상태를 나타낼 때 상태 아이콘(<code>*-filled</code>)을 쓴다
      </td>
      <td>선 아이콘에 상태색을 직접 칠해 비슷하게 만든다</td>
    </tr>
    <tr>
      <td>단독 아이콘에는 접근 가능한 이름을 준다</td>
      <td>의미를 알 수 없는 아이콘만 단독으로 둔다</td>
    </tr>
    <tr>
      <td>
        새 아이콘은 Figma에서 내보내 목록에 추가한다 (<code>docs/icon-workflow.md</code>)
      </td>
      <td>임의로 그린 SVG를 코드에 직접 붙여 넣는다</td>
    </tr>
  </tbody>
</table>

## 새 아이콘 추가 · 수정

Figma에서 SVG를 내보내 `src/assets/icons/`에 넣고 `pnpm icons`를 실행합니다. 파일 이름 규칙과 색 규칙, 이름을 따로 지정하는 방법은 저장소의 `docs/icon-workflow.md`를 참고합니다.
