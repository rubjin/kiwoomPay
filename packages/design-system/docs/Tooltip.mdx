# Tooltip / Info

Info 아이콘 · 버튼 같은 기준 요소에 **보조 설명**을 띄웁니다. 몸체는 Hug(최대 320)이고, 12 Regular 흰 글자에 Neutral 800 배경입니다.

```tsx
import { InfoTip, Tooltip } from '@kiwoompay/design-system';

<span>
  보유 메뉴 권한 <InfoTip content="현재 사용자에게 부여된 메뉴 접근 권한을 기준으로 산정합니다." />
</span>;

<Tooltip content="선택한 거래만 취소 요청합니다.">
  <Button size="sm">선택 취소</Button>
</Tooltip>;
```

## 2. Size & Auto Layout

<Canvas of={TooltipStories.SizeAndWrap} />

- Root / Surface: Hug × Hug. 짧은 문구는 내용 크기만큼 가로로 늘어납니다.
- 최대 너비 320(본문 296). 넘으면 자동 줄바꿈하고 높이가 함께 늘어납니다(잘리지 않음).
- 문자열의 줄바꿈(`\n`)은 그대로 표시합니다.

## 4. Usage & Behavior

<table>
  <thead>
    <tr>
      <th>표시 동작 · 기본 규칙</th>
      <th>배치 및 예외 · 기본 규칙</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
        Hover 200ms 후 표시(<code>delay</code>), 키보드 Focus는 즉시 표시
        <br />
        Pointer 이탈 · Focus 해제 · Esc 입력 시 닫기 (Esc는 모달보다 먼저 처리 — 툴팁만 닫힘)
        <br />
        보조 설명 전용: Tooltip 안에 입력창 · Action 버튼을 넣지 않는다
        <br />
        클릭해야 할 핵심 정보의 유일한 전달 수단으로 쓰지 않는다
      </td>
      <td>
        아이콘 끝과 포인터 끝이 맞닿도록 간격 0
        <br />
        기본 하단 배치, 공간이 모자라면 상단 → 왼쪽 → 오른쪽으로 전환
        <br />
        카드 Clip 영역의 영향을 받지 않는 Overlay 계층(document.body)에 표시
        <br />
        최대 너비 320, 본문 자동 줄바꿈 · 높이 Hug
      </td>
    </tr>
  </tbody>
</table>

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>용어 · 정책처럼 몰라도 업무는 할 수 있는 보조 설명에 쓴다</td>
      <td>필수 안내 · 오류 메시지를 Tooltip에만 둔다 (Helper Text · Infobox 사용)</td>
    </tr>
    <tr>
      <td>문구는 2~3줄 안으로 짧게 쓴다</td>
      <td>Tooltip 안에 링크 · 버튼 · 입력창을 넣는다</td>
    </tr>
    <tr>
      <td>Info 아이콘은 설명 대상 라벨 바로 옆에 둔다</td>
      <td>한 화면에 Info 아이콘을 과하게 늘어놓는다</td>
    </tr>
  </tbody>
</table>

## 토큰 · 확인 필요

- `tooltip/*` (`tokens/custom/tooltip.json`), `z-index/tooltip`. 색은 모두 alias (Neutral 800 · Text/Inverse · Icon/Muted)
- **임시 값(TODO)**: 화면 경계 최소 간격 8, z-index 1200(모달 · 드롭다운 위), 비활성 Info 아이콘 색
- 시안 표기는 "아이콘 ↔ 포인터 끝 0px"이고, 측정상 아이콘(20) 아래 1~2px 차이는 원 바깥 여백으로 판단해 0으로 구현했습니다
- 표시 · 숨김 애니메이션은 motion 토큰이 없어 넣지 않았습니다
