# Compact Navigation

`< 1 / 3 >` 형태로 현재 위치와 전체 개수를 보여주고 이전 · 다음으로 넘기는 작은 이동 컨트롤입니다.
카드 · 공지 · Carousel처럼 **좁은 영역에서 항목을 하나씩 넘길 때** 씁니다. 목록 화면의 페이지 이동은 `Pagination`을 씁니다.

```tsx
import { CompactNavigation } from '@kiwoompay/design-system';

<CompactNavigation total={3} page={page} onChange={setPage} />;
```

## 1. State

- 처음 위치에서는 **이전**, 마지막 위치에서는 **다음**이 비활성(회색)입니다.
- `loop`를 주면 끝에서 처음으로 이어서 넘기고 화살표가 비활성되지 않습니다.
- `disabled`는 두 화살표를 모두 비활성합니다.

## Spec

- 화살표 아이콘 16(`chevron-left` · `chevron-right`), 화살표 ↔ 번호 4
- 번호 12 SemiBold(`typo-12-semi-bold`), 번호 · 전체 Neutral 600(`Text/Secondary`), `/` Neutral 400(`Text/Disabled`)
- 화살표 Primary 700, 비활성 Neutral 400
