# Date Picker

날짜를 고르는 달력 패널입니다. **일별 선택(Single)** 과 **기간 선택(Range)** 두 가지 유형이 있고,
보통은 `DateField` · `DateRangeField`가 필드를 누르면 열어주므로 직접 쓸 일은 많지 않습니다.

```tsx
import { DateField, DateRangeField, DatePicker } from '@kiwoompay/design-system';

// 필드와 함께 (권장): 필드·달력 아이콘을 누르면 열리고, 고르면 값이 반영되며 닫힌다
<DateField value={date} onChange={setDate} />
<DateRangeField value={range} onChange={setRange} maxRangeDays={31} />

// 패널만 (화면에 펼쳐 두는 경우)
<DatePicker value={date} onChange={setDate} />
<DatePicker mode="range" value={range} onChange={setRange} />
```

날짜 값은 모두 `YYYY-MM-DD` 문자열이고, 기간은 `{ start, end }`입니다.

## 4. Range

- **Start · End**: Selected와 같은 채움. **Middle**: 연한 Primary 배경 · Primary 글자 · 모서리 없음.
- 첫 번째로 고른 날이 시작일, 두 번째가 종료일입니다. 종료일을 시작일보다 앞으로 고르면 그 날이 새 시작일이 됩니다.
- 종료일까지 골라야 `onChange`가 호출됩니다(필드에서는 이때 값이 반영되고 닫힙니다).

## Do / Don't

<table>
  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
        조회기간은 <code>DateRangeField</code> 하나로 받는다
      </td>
      <td>
        시작일 · 종료일을 <code>DateField</code> 두 개로 따로 받는다
      </td>
    </tr>
    <tr>
      <td>
        최대 조회기간이 있으면 <code>maxRangeDays</code>로 선택 단계에서 막는다
      </td>
      <td>아무 기간이나 고르게 한 뒤 조회 시점에 오류로 알린다</td>
    </tr>
    <tr>
      <td>
        선택할 수 없는 날짜는 <code>min</code> · <code>max</code> · <code>isDateDisabled</code>로
        비활성화한다
      </td>
      <td>선택은 되게 두고 저장할 때 막는다</td>
    </tr>
    <tr>
      <td>
        서버 기준 날짜가 중요하면 <code>today</code>를 서버 날짜로 넘긴다
      </td>
      <td>사용자 PC 시간이 틀려도 그대로 둔다</td>
    </tr>
  </tbody>
</table>

## 토큰

- 색: `date-picker/*` (`tokens/custom/datepicker.json`, 모두 Figma 색 alias). 컴포넌트 전용 크기 · 간격은 `*.module.scss` 맨 위 SCSS 변수(`DatePicker.module.scss`)
- 글자: 역할 이름 `body-md`(날짜) · `heading-sm`(제목)
- 필드와 패널 사이 간격(8)은 시안에 없어 **임시 값(TODO)** 입니다. 가맹점관리자 모바일 배치도 시안이 없어 적용하지 않았습니다.
