# Column Picker

내보낼 항목을 **고르고 순서를 정하는** 본문입니다(엑셀 다운로드 항목 설정 등). `Modal.Body`에 넣습니다.

```tsx
<Modal open={open} onClose={close} width={876}>
  <Modal.Header title="엑셀 다운로드" closeButton />
  <Modal.Body>
    <ColumnPicker items={items} onItemsChange={setItems} value={selected} onChange={setSelected} />
  </Modal.Body>
  <Modal.Footer>
    <Button size="lg" variant="neutral" appearance="line" onClick={close}>
      취소
    </Button>
    <Button size="lg" onClick={download}>
      다운로드
    </Button>
  </Modal.Footer>
</Modal>
```

| Prop                                  | 설명                                                         |
| ------------------------------------- | ------------------------------------------------------------ |
| `items` · `onItemsChange`             | 항목(이 순서로 표시). 드래그로 순서를 바꾸면 새 배열을 넘김  |
| `value` · `defaultValue` · `onChange` | 선택한 항목 value 배열(항목 순서대로)                        |
| `description`                         | 위쪽 안내 문구(기본 "다운로드 하고 싶은 항목을 선택하고, …") |
| `selectAllLabel`                      | 전체선택 문구. 일부만 선택되면 일부 선택(–) 표시             |
| `columns`                             | 한 줄 칸 수(기본 4)                                          |

## 동작

- 항목 칸을 끌어 다른 칸에 놓으면 그 자리로 옮겨집니다(브라우저 기본 Drag and Drop, 마우스).
- 체크박스로 선택, 전체선택으로 모두 선택 · 해제합니다.
- 실제 다운로드(선택 항목 · 순서로 파일 만들기)는 화면에서 처리합니다.
