# Favorite Menu Picker

LNB 즐겨찾기(MY 메뉴)를 고르는 **즐겨찾기 편집 Modal**의 본문입니다. LNB와 같은 메뉴 트리(`LnbMenuItem[]`)를 받습니다.

```tsx
<Modal open={editing} onClose={close} size="md">
  <Modal.Header
    title="즐겨찾기 편집"
    closeButton
    addon={<FavoriteCount count={draft.length} max={10} />}
  />
  <Modal.Body>
    <FavoriteMenuPicker items={menu} value={draft} onChange={setDraft} />
  </Modal.Body>
  <Modal.Footer>
    <Button size="lg" variant="neutral" appearance="line" onClick={close}>
      취소
    </Button>
    <Button size="lg" onClick={save}>
      저장
    </Button>
  </Modal.Footer>
</Modal>
```

| Prop                                  | 설명                                                     |
| ------------------------------------- | -------------------------------------------------------- |
| `items`                               | 메뉴 트리. 하위가 없는 메뉴(3Depth 등)만 체크박스로 고름 |
| `value` · `defaultValue` · `onChange` | 선택한 메뉴 id 배열                                      |
| `max`                                 | 최대 개수(기본 10). 다 차면 나머지는 비활성              |
| `defaultOpenIds`                      | 처음 펼칠 1 · 2Depth id                                  |
| `description` · `searchPlaceholder`   | 안내 · 검색 문구                                         |
| `FavoriteCount`                       | 헤더의 "선택한 메뉴 N / 10" (`Modal.Header`의 `addon`)   |

## 동작

- 1Depth · 2Depth를 눌러 펼치고 접습니다. 메뉴 검색어를 넣으면 일치하는 메뉴만 남기고 모두 펼칩니다.
- 최대 개수를 채우면 선택하지 않은 메뉴는 비활성됩니다.
