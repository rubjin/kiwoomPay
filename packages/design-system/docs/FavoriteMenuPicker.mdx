# Favorite Menu Picker

LNB 즐겨찾기(MY 메뉴)를 고르는 **즐겨찾기 편집 Modal**의 본문입니다 (페이지 패턴 P07 V01). LNB와 같은 메뉴 트리(`LnbMenuItem[]`)를 받습니다.
기준: Figma KWPC1301 LNB 즐겨찾기 편집 팝업(29348:37).

```tsx
<Modal open={open} onClose={close} size="lg">
  <Modal.Header title="즐겨찾기 편집" closeButton />
  <Modal.Body>
    <FavoriteMenuPicker items={menu} value={config.draft} onChange={config.setDraft} />
  </Modal.Body>
  <Modal.Footer>
    <Button size="lg" variant="neutral" appearance="line" onClick={close}>
      취소
    </Button>
    <Button size="lg" disabled={!config.dirty} onClick={() => save.execute()}>
      저장
    </Button>
  </Modal.Footer>
</Modal>
```

| Prop                                  | 설명                                                     |
| ------------------------------------- | -------------------------------------------------------- |
| `items`                               | 메뉴 트리. 하위가 없는 메뉴(3Depth 등)만 체크박스로 고름 |
| `value` · `defaultValue` · `onChange` | 선택한 메뉴 id 배열 (선택한 순서 = 칩 순서)              |
| `max`                                 | 최대 개수(기본 10). 다 차면 나머지는 비활성              |
| `defaultOpenIds` · `defaultQuery`     | 처음 펼칠 1 · 2Depth id, 처음 검색어                     |
| `searchPlaceholder` · `selectedLabel` | 검색 · 즐겨찾기 메뉴 상자 문구                           |

## 동작

- **즐겨찾기 메뉴 상자**: "즐겨찾기 메뉴 N / 10" + 선택한 메뉴 칩. 칩의 x로 빼고, 칩이 넘치면 → 버튼으로 옆으로 넘긴다
- **메뉴 트리**: 1Depth · 2Depth를 눌러 펼치고 접는다. 넘치면 트리 안에서 스크롤 (최대 445)
- **검색**: 트리 대신 일치하는 메뉴 목록 — 이름(검색어 Primary 강조) + 경로(1Depth > 2Depth)
- 최대 개수를 채우면 선택하지 않은 메뉴는 비활성
