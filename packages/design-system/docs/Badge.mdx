# Badge

상태 · 속성 · 분류를 짧게 표시하는 Text Badge와, 건수를 보여주는 Number Badge, 신규 표시용 Dot Badge가 있습니다.

```tsx
import { Badge, NumberBadge, DotBadge, UnreadIndicator } from '@kiwoompay/design-system';

<Badge tone="success" dot>정상</Badge>          {/* 상태 */}
<Badge tone="primary" appearance="line">주요</Badge> {/* 속성·분류 */}
<NumberBadge count={unread} />                  {/* 건수 (99+) */}
<DotBadge aria-label="새 기능" />                {/* 신규 기능·메뉴 */}
```

- 독립 Dot Badge는 신규 기능 · 메뉴 업데이트 표시용이며, 상태 Badge 안의 Status Dot과 구분합니다.

<Canvas of={BadgeStories.NumberAndDot} />

### Unread Indicator

읽지 않은 알림 · 게시물 · 메시지 이름 옆에 `N`을 붙여 표시합니다(`UnreadIndicator`). 11 Bold · Primary 500.

- 읽으면 화면에서 지웁니다. 건수가 필요하면 Number Badge를 씁니다.
- 신규 **기능 · 메뉴** 표시는 `DotBadge`, 읽지 않은 **항목** 표시는 `UnreadIndicator`로 구분합니다.
- 기본 `aria-label`은 "읽지 않음"입니다.

**StatusDot 선택 기준 · 기본 Hide / 필요 시 Show**

- 기본 상태 · Hide: 계정 · 로그인 상태 등 단독 상태 표시
- 상태 비교 · Show: 여러 상태를 비교하는 목록 · 모니터링
- 분류 · 속성 · Hide: 카테고리 및 속성값은 Dot 없이 표시

<Canvas of={BadgeStories.StatusDotUsage} />

동일 화면 · 정보 그룹에서는 Dot 노출 기준을 일관되게 적용합니다. 상태의 의미와 중요도는 Dot이 아니라 **레이블과 Tone**으로 구분합니다.

## Do / Don't

  <thead>
    <tr>
      <th>Do</th>
      <th>Don't</th>

  <tbody>
    <tr>

    </tr>
    <tr>
      <td>
        신규 표시는 <code>DotBadge</code>를 쓴다

    </tr>
    <tr>
