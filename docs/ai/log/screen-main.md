## 참조

### KWPC0104 다운로드 센터 (`features/main/download-center/`)

- 진입 시 바로 조회(내 요청 목록이라 "최초 진입 시 조회하지 않음"의 예외). 헤더 [다운로드 센터] → 이 화면
- 검색 조건이 한 줄이라 `SearchPanel actionsPlacement="inline"`(버튼이 필드 줄 끝, 접기 없음). 상단 안내는 `Infobox.Item` 제목 없이 한 줄
- 행별 작업 규칙(`downloadActions`): 완료 + 다운로드 가능 → [다운로드], 실패 → [재시도], 완료 + 만료 → [재요청], 생성중 → 없음. 재시도 · 재요청은 Confirm → 요청 → `refresh()` → 완료 Alert. 상세 팝업(1056) Footer도 같은 규칙
- 공통코드 `DOWNLOAD_AREA` · `DOWNLOAD_STATUS` · `DOWNLOAD_FILE_STATUS`. 데이터는 예시(TODO API)
